# Hermes Knowledge Signal Filter

## Purpose

Filter collected content before analysis.

Hermes prioritizes capability improvement over news collection.

---

# Priority Order

```
Methodology
    >
Workflow
    >
Prompt Method
    >
Tool Evaluation
    >
News
```

---

# Keep

## Workflow

Examples:

- ChatGPT production workflows
- AI agent systems
- automation pipelines
- creative production processes

## Methodology

Examples:

- problem solving frameworks
- prompt systems
- storytelling methods
- research methods

## Prompt Method

Examples:

- reusable prompt structures
- image direction systems
- character consistency methods
- iterative prompting

---

# Lower Priority

## Tool Evaluation

Keep only when it reveals:

- workflow improvement
- capability changes
- new production methods

---

# Reject

Do not prioritize:

- software advertisement
- benchmark-only content
- simple feature introductions
- repeated news summaries

---

# Analysis Queue Rule

A source enters deep analysis when it has at least one:

- reusable workflow
- repeatable methodology
- prompt framework
- Hermes skill impact
