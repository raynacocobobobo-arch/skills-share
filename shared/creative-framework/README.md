# Hermes Creative Framework Index

## 定位

本目录是共享创作方法的轻量索引，不是中央 Router，也不替代任何 canonical `SKILL.md`。

使用顺序：

```text
任务
↓
canonical Skill
↓
当前问题需要时读取对应 Creative Framework
↓
需要更深方法时读取专业书 .index.md
↓
只精读索引指向的原文章节
```

不要默认加载全部 Framework，也不要默认加载整本专业书。

## Film

- `film/screenwriting-directing.md`：故事结构、人物行动、冲突、场景功能与导演介入。
- `film/storyboard-directing.md`：镜头目的、空间调度、景别、动作与节奏。
- `film/visual-language-directing.md`：把文本意义转成构图、运动、声音、节奏与观众体验。
- `film/documentary.md`：纪录片、纪实表达、人物访谈、现场行动与真实叙事。
- `film/creative-decision-map.md`：根据故事、视觉、分镜和节奏症状选择对应 Film Framework。

## Promotional Film

- `promo/corporate-film.md`：企业宣传片、央国企形象片、政府/产业汇报片、招商片与国际传播片的价值与证据判断。

## Marketing

- `marketing/strategy.md`：营销诊断、目标客户、竞争替代、定位、价值主张与连贯行动。

## Deep-read Sources

Creative Framework 只负责创作判断。需要教材级方法时，优先进入：

`shared/source-library/专业书/*.index.md`

由索引决定是否读取原文以及读取哪个章节。

## 边界

- `Skill = entry`
- `Creative Framework / Reference = method`
- `Source = evidence`
- `Workflow = cross-skill orchestration`

本目录不得演化成新的中央治理层，也不得覆盖用户/客户已确认内容、项目事实、专业安全边界或 canonical Skill 的任务规则。
