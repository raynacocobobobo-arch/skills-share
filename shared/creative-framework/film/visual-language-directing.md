# Visual Language + Directing Framework

## 定位

用于“剧本能看懂，但不像电影”、视觉表达依赖解释、镜头缺乏导演动机等问题。

本 Framework 负责把文本判断转成可感知的导演表达，不替代分镜 Skill，也不替代专业书。

## 核心转换

```text
文本意义
↓
人物行动与空间关系
↓
构图 / 运动 / 声音 / 节奏
↓
观众注意力与体验
```

## 场景设计

选镜头前先判断：

- 人物此刻想要什么；
- 场景里真正发生了什么变化；
- 观众现在必须知道什么；
- 观众现在应该感受到什么；
- 哪些信息可以通过动作、空间或声音表达，而不是解释。

## 视觉判断

优先使用：

- 行动；
- 人物与环境的空间关系；
- 构图与视线；
- 前中后景关系；
- 声音与画面的互补；
- 镜头长短与节奏变化。

避免用“电影感、史诗感、高级感”等抽象词代替可执行判断。

## 镜头价值

一个镜头至少应承担一项：

- 提供新信息；
- 改变情绪；
- 改变人物关系；
- 建立或改变空间认知；
- 完成动作或意义上的转折。

如果没有新增价值，优先删除、合并或重新设计。

## 深读路由

需要更具体的导演、视听、场面调度、摄影或剪辑方法时，先读：

- `shared/source-library/专业书/导演创作手册.index.md`
- `shared/source-library/专业书/影视综合技巧.index.md`

只有索引明确指向且当前问题确实需要时，再读取对应原文章节。不要默认加载整本专业书。

## 输出检查

- 是否用可见可听的方式表达意义；
- 镜头是否有叙事动机；
- 空间和人物调度是否先于炫技运镜；
- 观众注意力是否被清楚组织；
- 专业方法是否服务当前任务，而不是覆盖项目事实与已确认内容。
