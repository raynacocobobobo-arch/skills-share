# Screenwriting + Directing Framework

## Purpose

用于故事片、微电影、剧情宣传片、AI短片等任务中的编剧与导演联合判断。

它不是剧本模板，而是帮助 Hermes 判断：故事为什么成立、人物为什么行动、画面如何表达。

## 使用时机

当任务涉及：

- 故事结构设计
- 人物弧线
- 戏剧冲突
- 三分钟短片
- 少对白视觉叙事
- 剧情宣传片

先读取本 Framework，再决定调用专业书章节。

## 核心判断顺序

### 1. 先判断人物行动

不要先设计情节。

先回答：

- 主角想得到什么？
- 为什么现在必须行动？
- 什么阻碍他？
- 他做出的选择改变了什么？

### 2. 冲突来自选择

有效冲突不是制造事件，而是：

人物目标、现实限制、价值选择之间发生碰撞。

### 3. 用画面代替解释

优先检查：

- 一个动作是否能表达信息？
- 一个场景是否具有叙事功能？
- 一个物件是否可以形成意义变化？

## 导演判断

导演判断贯穿编剧过程：

- 什么必须被看到？
- 什么不应该被说出来？
- 观众应该什么时候知道信息？
- 情绪来自事件还是来自人物选择？

## 专业资料调用

需要深入方法时，根据 index 调用：

- 故事片创作
- 影视综合技巧
- 电影编剧相关资料

不要默认读取全部原文。

## 输出检查

完成前检查：

- 故事是否由人物行动推动？
- 每个关键场景是否改变状态？
- 高潮是否由前面因果产生？
- 是否能减少解释性对白？
