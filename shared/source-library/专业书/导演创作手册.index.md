## 什么时候读

当任务涉及主题落地、冲突与节拍、用动作替代解释、镜头动机、构图与剪辑、纪录片观察方式、演员调度或剧本可拍性时，先读本索引。

## 章节 / 主题目录

- 第2章：确定电影的主题——主题来源、避免说教、现实素材转电影创意。
- 第3章：故事的戏剧化关键——冲突、角色目标、节拍、戏剧性单元、场景与幕。
- 第4章：导演的银幕语法——镜头运动、并置、动作匹配、声画、视点、潜文本、节奏。
- 第5章：站在电影制作者的角度思考——构图、视觉节奏、摄影机位置、剪辑动机、场面调度。
- 第6章：拍摄练习——动作连续性、情绪弧线、旁白与画面、平行叙事。
- 第7章：鉴别优秀剧本——视觉动作、场景功能、人物动机、心理与行为矛盾。
- 第8章：分析剧本——因果链、障碍、情节点、人物发展、对白与分场大纲。
- 第9章：导演的发展策略——铺垫、延后阐释、动作替代语言、置换与潜台词。
- 第10章：可供选择的故事来源——改编、主题 / 角色 / 事件启动、美学与视点。
- 第18章：指导演员——动作目标、潜台词、反应与导演沟通。
- 第20章：带剧本的表演练习——台词 / 动作、节拍、戏剧性单元、戏剧主线。

## 任务路由

| 任务 | 优先章节 | 用途 |
|---|---|---|
| 宣传片主题空泛、口号化 | 第2章、第9章 | 从抽象价值落到人物、事件、动作和细节 |
| 故事缺冲突、推进慢 | 第3章、第8章 | 检查目标、障碍、节拍、情节点和因果链 |

| 纪录片太说明、像采访拼接 | 第4章、第5章、第6章 | 建立观察者 / 讲述者立场，用行动与剪辑组织真实 |
