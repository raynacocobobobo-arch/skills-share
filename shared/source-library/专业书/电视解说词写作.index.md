## 基本信息

- 原文：`shared/source-library/专业书/电视解说词写作.md`
- 类型：电视解说词 / 非虚构叙述 / 纪录片 / 观众意识 / 主题 / 结构 / 词句段章 / 声画关系
- 适用技能：`hermes-film-宣传片创作`；`hermes-film-故事片创作` 中的纪实 / 旁白任务可按需参考。

## 什么时候读

- 宣传片解说词像材料汇编、汇报稿或口号堆积；
- 政府 / 央国企汇报片需要在真实材料基础上建立叙述结构；
- 纪录片 / 纪实片需要处理事实、观点、主题、采访和旁白之间的关系；
- 解说词与画面重复，缺少互补关系；
- 文案句子太书面、段落不顺、章法松散；
- 需要从前期资料、专家采访、实地采访进入正式撰稿。

## 任务路由

| 任务 | 优先章节 | 用途 |
|---|---|---|
| 政府 / 国企汇报片材料很多，不知道怎么组织 | 第6、7、8章 | 先做资料认知，再确定主题工具和叙述结构 |
| 宣传片文案像 PPT 条目拼接 | 第8、9章 | 用整体结构、段落关系和章法重组信息 |
| 文案没有观众感，只顾“我是谁” | 第3章 | 用观众意识检查信息选择、解释程度和叙述角度 |
| 纪实片既要真实又要有观点 | 第4、7章 | 区分事实基础、作者在场和主题组织，不假装绝对无主体 |
| 解说词重复画面 | 第10章 | 重新设计互补、延伸、对位或结构功能 |
| 句子太长、书面腔重 | 第9章 | 从词、句、段、章四层检查口语可听性与节奏 |
| 客户只给资料，尚未形成写作判断 | 第6章 | 先阅读资料、必要时补专家 / 实地采访，再进入写作 |
| 纪录片采访很多但没有片子结构 | 第7、8章 | 从主题筛选素材，再建立叙述结构，而不是按采访对象排列 |

## 深读触发条件

当任务需要处理具体的非虚构结构、观众意识、主题与事实的关系、词句段章或声画关系时，读取对应章节；如果只是普通企业宣传片结构且现有 `宣传片创作` references 已足够，不要额外加载原文。

## 使用边界

- 本书的方法不能替代事实核验；涉及数字、政策、历史、机构表述时以项目材料和可靠来源为准。
- 不能因为本书讨论“主题”就把事实硬拗成预设结论；主题负责组织事实，不负责创造事实。
- 先服从当前 `宣传片创作` skill 的 source/fact states、revision mode 和 minimum-diff 规则。
