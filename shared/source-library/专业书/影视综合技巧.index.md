| 任务 | 优先章节 | 用途 |
|---|---|---|
| 宣传片缺视觉概念 | 1.1、1.3、2.3、6 | 从主题转到视听、美术和风格统一 |
| 政府汇报片太像 PPT | 1.2、1.3、2、剪辑技术 | 把材料组织为视听段落，而不是文字条目依次上屏 |
| 故事片需要导演层分析 | 1.1–1.4、4 | 联动主题、剧本、视听语言和场面调度 |

| 人物访谈片只有“坐着说” | 3.4、1.4、7.2 | 从人物行动、环境、构图和调度增加视觉叙事 |
| 分镜需要深入场面调度 | 1.3、1.4 | 补视听语言和空间组织；具体分镜优先读分镜专项索引 |
| 工业片现场光线 / 构图判断 | 7.2、光线技术、实景照明 | 在真实场地条件下规划可拍视觉方案 |
| 后期节奏松散 | 剪辑与省略、节奏性、剪辑意图 | 判断哪些内容可省略、为什么切、如何建立段落节奏 |
| 声音只是背景音乐 | 8 + 音乐与剪辑 | 将环境声、声音动机、音乐和剪辑共同纳入叙事 |

## 深读优先级

1. 如果是纯分镜：先读 `影视综合技巧-分镜完整整理.index.md`。
2. 如果是纯解说词 / 纪实文本：先读 `电视解说词写作.index.md`。
3. 如果是纯故事结构：先读 `故事片创作.index.md` 或 `电影编剧创作指南.index.md`。
4. 只有跨工种、风格、纪录片、摄影 / 剪辑等问题需要补充时，再读本书对应章节。

## 使用边界

- 本书是“大综合参考”，不应成为每个 film skill 的默认全量依赖。
- 摄影、录音、设备等技术内容可能随技术发展变化；涉及具体设备规格或当前制作规范时应另行核验。
- 所有参考先服从当前 canonical `SKILL.md`、项目事实和拍摄可行性。
