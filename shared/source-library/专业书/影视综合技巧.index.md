# 影视综合技巧 Index

## 用途

用于导演、编剧、分镜、视觉设计、剪辑等影视任务的综合方法参考。

## 适用任务

- 故事短片开发
- AI电影创作
- 剧情宣传片
- 分镜设计
- 视觉风格设计
- 导演方案分析

## 核心能力地图

### 导演技术
解决：如何从主题、人物和戏剧需求出发进行整体创作判断。

关键词：
- 主题
- 剧本分析
- 视听语言
- 场面调度
- 演员指导

### 编剧技术
解决：故事结构、人物行动、冲突和剧本组织。

关键词：
- 故事来源
- 人物
- 结构
- 戏剧冲突

### 摄影与视觉语言
解决：如何通过画面表达意义。

关键词：
- 构图
- 光线
- 镜头运动
- 视觉风格

### 剪辑与节奏
解决：如何控制信息释放和情绪变化。

关键词：
- 节奏
- 镜头关系
- 时空组织
