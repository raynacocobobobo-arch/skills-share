## 什么时候读

当任务需要回答“卖给谁、为什么买、与谁竞争、如何定位、通过什么渠道触达、如何形成价值与满意度、如何建立品牌”时，先读本索引。

普通文案润色、简单广告语、单次社媒标题等，如果不涉及营销判断，不需要读原文。

## 主题目录（功能型）

> 当前原文整理版并非所有位置都保留稳定章节号，因此本索引按可检索主题组织。

### 营销的价值与基本范畴

- 营销与企业盈利、需求和销售的关系
- 产品、服务、观念等营销对象
- 消费者市场、企业市场、政府 / 非营利市场的差异

### 需要、欲望与需求

- 表明需求、真实需求、未表明需求、愉悦需求、隐秘需求
- 区分顾客说出的需求与真正驱动购买的需求

### 市场细分、目标市场与定位

- 识别人群差异
- 选择更有机会的目标市场
- 为目标客户建立清晰的关键利益定位

### 价值主张、供应物与品牌

- 用利益组合形成价值主张
- 产品 / 服务 / 体验承载价值
- 品牌联想、品牌形象与差异化

### 营销渠道与媒体

- 传播渠道、分销渠道
- 付费媒体、自有媒体
- 线上 / 线下渠道与触点组合

### 顾客价值与满意度

- 质量、服务、价格之间的价值关系
- 顾客期望、感知性能与满意度
- 获取、维持和增加顾客

### 竞争与替代

- 不只看直接竞争者，还要识别潜在竞争与替代方案
- 避免把竞争范围定义得过窄

### 消费者与企业的新能力

- 信息透明、比较、评论和线上购买
- 企业收集市场 / 顾客 / 竞争信息与实验创新
- 线上线下融合

### 营销观念与跨部门协同

- 产品观念、推销观念、营销观念的差异
- 营销不是营销部门单独完成的工作
- 产品、销售、渠道、服务等共同参与顾客价值创造

## 任务路由

| 任务 | 优先主题 | 用途 |
|---|---|---|
| 生意有曝光但没有成交 | 需要 / 需求 + 顾客价值 | 判断触达的人是否真有需求，价值是否足以驱动购买 |
| 不知道核心客户是谁 | 细分 / 目标市场 / 定位 | 划分市场并选择优先服务的人群 |
| 产品看起来和竞品差不多 | 定位 + 价值主张 + 竞争与替代 | 找关键利益、使用场景和替代方案，而不是只比较功能 |
| 客户只说“太贵” | 真实需求 + 顾客价值 | 区分价格问题、价值感知问题和目标客群错配 |
| 需要做品牌 | 品牌 + 定位 | 建立强、有利、独特的品牌联想并与目标市场一致 |
| 获客渠道混乱 | 营销渠道与媒体 | 区分传播、分销、付费 / 自有媒体及其角色 |
| 做完整营销计划 | 全部主题，优先 STP → 价值 → 渠道 → 竞争 | 从市场选择到行动组合形成完整逻辑 |
| 政府 / 企业客户营销 | 市场类型差异 | 识别专业买家、组织采购、声誉、价格和可操作性的重要性 |
| 想做营销实验 | 消费者 / 企业新能力 | 保留稳定投入，同时安排可学习的小规模实验 |

## 深读触发条件

- 需要完成 STP、价值主张、品牌、渠道或竞争分析中的具体一环；
- marketing skill 当前方法不足以解释顾客需求层次或替代竞争；
- 需要为完整营销计划建立教材级框架校验；
- 用户要求根据市场营销理论解释现有业务问题。

## 使用边界

- 教材框架不能替代当前市场数据、区域收入、平台规则、竞品价格或消费者调研；这些需要另外检索或由用户提供。
- 不把所有 4P / STP 概念机械塞进每个回答。只读取与当前问题直接相关的部分。
- `marketing-copilot` 用于诊断和建议；`marketing-plan` 用于完整计划。原文服务于两者，但不改变 skill 的路由边界。
