# 《故事片创作》Reference Index

> 任务路由索引，不替代原文。用于把故事创意、文字剧本和场景设计转化为可拍摄的故事片 / 短片表达。

## 基本信息

- 原文：`shared/source-library/专业书/故事片创作.md`
- 类型：故事片创作 / 短片 / 剧本 / 视听语言 / 摄影机运动 / 连续性 / 场景设计
- 适用技能：`hermes-film-故事片创作`、`hermes-film-影视分镜`；宣传片中的故事化段落可按需参考。

## 什么时候读

当任务涉及短片故事构思、主角目标与阻碍、故事是否适合短时长、剧本视觉化、对白转行动、人物塑造、场景与视点、摄影机运动或连续性时读取本索引。

## 章节 / 主题目录

### 第一章：从创意到电影故事

- 从观察和个人经验形成创意
- 主角、目标、阻碍 / 冲突
- 事件推进与冲突升级
- 结局与核心戏剧问题
- 短片故事的紧凑、简单、高效原则
- 悬疑 / 疑问驱动的短片叙事
- 创意与实际制作条件的匹配

### 剧本写作与视觉化

- 场景标题、动作、对白、画外音 / 旁白等基本写法
- “通过行动呈现人物”，减少说明性对白
- 用段落区分视点、戏剧小节和关键动作
- 通过词汇、语法、行动和声音塑造人物
- 改写与剧本精炼

### 视觉与摄影机语言

- 画幅、构图和运动画面
- 横摇、纵摇、推拉、追随、升降及组合运动
- 摄影机运动的故事动机与场景内动机
- 运动结束时应带来新信息或新理解

### 连续性与可剪性

- 单摄影机制作与连续性体系
- 场面调度连续性
- 服装、道具、灯光、声音连续性
- 表演、动作、位置与情感强度连续性
- 空间连续性与 180 度原则

## 任务路由

| 任务 | 优先主题 | 用途 |
|---|---|---|
| 3–5 分钟短片故事太大、太散 | 第一章：短片故事 | 缩小创意规模，保留可识别人物、单一核心冲突和关键转折 |
| 主角没有行动力 | 第一章：主角 / 目标 / 阻碍 | 明确人物要什么、什么阻止他、他采取什么行动 |
| 故事只有设定没有推进 | 第一章：事件推进与冲突升级 | 将设定变成逐步升级的行动—反应链 |
| 剧本解释多、画面少 | 剧本写作与视觉化 | 把情感、意图和人物特征转成可见行动 |
| 对白不能区分人物 | 人物与声音 | 用人物行动、词汇、语法和节奏建立差异 |
| 分镜运镜随意 | 摄影机运动的动机 | 每次运动都明确其叙事承诺和场景内触发原因 |
| 拍摄后难剪 | 连续性与可剪性 | 提前检查动作、位置、空间、声音和表演连续性 |
| 故事化宣传片段落不够像“戏” | 第一章 + 剧本视觉化 | 补主角、目标、阻碍、动作与转折，而不是只做情绪蒙太奇 |

## 深读触发条件

当当前 Story Skill 的方法仍无法解决具体的短片规模、行动设计、场景视觉化、摄影机动机或连续性问题时，读取原文对应部分。若只是普通故事结构检查，不要默认读取整本。

## 使用边界

本书服务于可拍摄的叙事设计。涉及行业事实、真实流程、地点设备或客户资料时，仍应使用外部事实核验或项目资料，不以本书替代事实来源。
