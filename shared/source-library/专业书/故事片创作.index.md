# 故事片创作 Index

## 用途

用于剧情创作、短片开发和故事结构诊断。

## 适用任务

- 故事短片
- AI剧情片
- 人物故事设计
- 剧情宣传片

## 核心能力地图

### 故事结构
解决：如何建立完整的戏剧推进。

关键词：
- 起承转合
- 冲突
- 转折
- 高潮

### 人物塑造
解决：人物为什么行动，以及如何产生变化。

关键词：
- 目标
- 欲望
- 缺陷
- 选择
- 成长

### 场景设计
解决：每个场景为什么存在。

关键词：
- 信息
- 冲突
- 状态变化

## 调用方式

适合在 screenwriting-directing framework 判断后调用。

重点读取与当前问题相关章节。
