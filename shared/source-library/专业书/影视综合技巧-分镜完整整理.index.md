当用户需要可执行分镜、镜头表、机位和走位设计、动作 / 对话场景拆分、场面调度、情绪节奏、拍摄顺序、分镜秒数或拍摄后可剪性时，优先使用本索引。

## 深读触发条件

- 当前分镜需要具体站位模型、纵深调度或动作连续性方法；
- 需要把文字脚本转为拍摄表、俯视图或可执行的镜头顺序；
- 需要区分广告式短镜头和故事片式完整镜头；
- 现有 `影视分镜` / `石化简易分镜` skill 只给出原则，尚不足以解决现场执行细节。

## 使用边界

分镜必须服从当前项目的真实地点、设备、演员、时间和安全条件。涉及工业 / 石化事实与现场流程时，先按相应 skill 做事实与可拍性核验，再使用本书做镜头组织。
