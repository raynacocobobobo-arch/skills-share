## 章节 / 主题目录（功能型）

> 原文是完整编剧教程，当前索引按 Hermes 常见任务提炼功能主题，不复制大段教材内容。

### 电影剧本的基本形式

- 电影剧本是用画面、对白和描写讲述的故事
- 视觉呈现优先于纯说明
- 线性与非线性叙事都需要清晰的结构支点

### 主题与故事焦点

- 明确故事“关于什么人、什么事”
- 主题作为人物与行动的组织中心
- 区分表面事件与真正的戏剧核心

### 人物与人物传记

- 建立主要人物的过去、职业生活、个人生活与私人生活
- 用人物需求、选择和行为驱动剧情
- 人物与情节相互作用，而不是孤立设计人物小传

### 戏剧性结构

- 开端 / 中段 / 结尾
- 建置、对抗、解决
- 关键事件、情节点和结构转折
- 通过结构把故事材料组织成可持续推进的行动线

### 场景与段落

- 场景必须承担故事功能
- 每场戏需要推进人物、行动或信息
- 场景之间形成因果、压力和方向，而不是素材堆积

### 非线性叙事

- 闪回、回忆、旁白、多线结构可以改变顺序，但不能失去关键事件和结构轴心
- 先明确故事整体，再决定叙述顺序

### 写作准备与改写

- 在正式写作前完成主题、人物、故事线和结构准备
- 初稿后回到故事焦点、人物行为和结构功能进行改写

## 任务路由

| 任务 | 优先主题 | 用途 |
|---|---|---|
| 有创意但说不清故事核心 | 主题与故事焦点 | 确定故事真正关于什么人、什么事 |
| 人物设定很多但剧情不动 | 人物 + 戏剧性结构 | 将人物需求、选择、行为接到行动线上 |
| 中段塌陷 | 戏剧性结构 | 检查对抗、压力升级、关键事件和情节点 |
| 开头信息太多 | 结构 + 场景 | 区分建置所必需的信息与可以延后的信息 |
| 场景好看但删掉也不影响剧情 | 场景与段落 | 检查场景是否承担人物、行动、冲突或信息功能 |
| 非线性故事看不懂 | 非线性叙事 | 先恢复核心事件与因果轴，再重新排列时间顺序 |
| 故事只有“发生什么”，没有人物变化 | 人物 + 主题 | 让人物选择和行为成为故事意义的一部分 |
| 需要系统重写剧本 | 写作准备与改写 | 先回到主题 / 人物 / 结构，再做逐场改写 |

## 深读触发条件

只有当 Story Skill 已经确定总体创作方向，但需要对主题、人物、情节点、结构段落、非线性叙事或系统改写做更细的剧作诊断时，读取原文对应部分。

## 使用边界

- 不把固定页数或单一结构比例当成所有短片的硬规则；根据实际时长、媒介和任务调整。
- 先服从 canonical `SKILL.md` 的任务模式与 revision control，再使用本书补充剧作判断。
