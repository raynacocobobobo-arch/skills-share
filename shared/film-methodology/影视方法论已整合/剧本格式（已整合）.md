### **一、基础设置**

#### **1. 页面设置**

- **纸张**：A4纸（210mm × 297mm）
- **页边距**：
    - 上边距：2.5厘米
    - 下边距：2.5厘米
    - 左边距：3厘米（为装订预留空间）
    - 右边距：2.5厘米
- **字体**：
    - **主字体**：宋体（小四号/12磅）或 黑体（标题部分）
    - **对白字体**：楷体（小四号/12磅）或 宋体（可根据个人偏好）
    - **场景标题**：黑体（小四号/12磅）或 宋体加粗
- **行距**：1.5倍行距（便于阅读和修改标注）
- **段落间距**：段前段后0行

#### **2. 页码**

- **位置**：页面右上角或右下角
- **格式**：阿拉伯数字（1, 2, 3...）
- **起始**：封面不计页码，正文从第1页开始编号

---

### **二、核心元素格式详解**

#### **1. 场景标题（场标）**

**格式**：`内/外景. 地点 - 时间`

**示例**：

文本

编辑

```
1内景. 咖啡馆 - 日
```

文本

编辑

```
1外景. 街道 - 夜
```

文本

编辑

```
1内/外景. 汽车 - 黄昏
```

**详细说明**：

- **内景/外景标识**：
    - `内景` = 室内场景
    - `外景` = 室外场景
    - `内/外景` = 室内外都有戏份
- **地点**：简洁明确，可加简短修饰
    - 例：`内景. 李奇公寓客厅 - 夜`
    - 例：`外景. 城市天台 - 黎明`
- **时间**：常用"日/夜"，特殊时间可写"黄昏/清晨/午后"等
- **字体**：黑体或宋体加粗，左对齐

---

#### **2. 动作描述（叙述）**

**位置**：场景标题下方，左对齐

**示例**：

文本

编辑

```
1内景. 咖啡馆 - 日
2
3咖啡馆内灯光昏暗，空气中弥漫着咖啡的香气。李奇坐在靠窗的位置，手指无意识地搅动着杯中的咖啡。他不时抬头看向门口，神情焦虑。
4
5王明推门而入，风尘仆仆。他环顾四周，很快发现了李奇，快步走来。
```

**格式要点**：

- **字体**：宋体，小四号
- **时态**：使用现在时（"李奇坐下"而非"李奇坐下了"）
- **内容**：只描述**可见、可听**的内容，避免心理描写
- **段落**：每段3-5行，空一行分隔不同动作单元
- **重要元素**：首次出现的角色名、关键道具可用**黑体**或**下划线**标注

---

#### **3. 角色名称**

**位置**：对白上方，居中

**格式**：

文本

编辑

```
1                    李奇
```

**详细说明**：

- **字体**：黑体或宋体加粗，小四号
- **对齐**：页面水平居中
- **首次出现**：角色第一次出场时，在动作描述中用**黑体**标注姓名和简要特征
    
    文本
    
    编辑
    
    ```
    1一个身影从阴影中走出。是**李奇**（三十岁，眼神锐利，衣着朴素）。
    ```
    
- **离场提示**：角色离开场景时可标注
    
    文本
    
    编辑
    
    ```
    1                李奇
    2        （起身）
    3        我先走了。
    4
    5（李奇转身离开）
    ```
    

---

#### **4. 对白**

**位置**：角色名称下方，居中

**格式**：

文本

编辑

```
1                    李奇
2            我不知道还能相信谁。
3            
4                    王明
5            你必须相信我。这件事只有我们两个知道。
```

**格式要点**：

- **字体**：楷体或宋体，小四号
- **对齐**：页面水平居中，左右各缩进约5-6个字符
- **行宽**：每行对白控制在20-25个汉字以内
- **标点**：使用中文全角标点（，。！？等）
- **语气标注**：尽量少用括号备注，让对白本身传递情绪

---

#### **5. 括号备注（语气/动作说明）**

**位置**：角色名称与对白之间，或对白中间

**格式**：

文本

编辑

```
1                    王明
2            （看着窗外，声音低沉）
3            也许我们一开始就错了。
```

**使用原则**：

- **字体**：宋体，小四号，可加括号
- **内容**：简要说明说话语气、伴随动作或对象
- **频率**：尽量少用，避免"导演式写作"
- **替代表达**：优先通过上下文和对白本身传递信息

---

#### **6. 转场**

**位置**：场景结尾，右对齐

**常用转场**：

文本

编辑

```
1                                                            切至：
```

文本

编辑

```
1                                                            淡入：
```

文本

编辑

```
1                                                            淡出。
```

文本

编辑

```
1                                                            叠化至：
```

**使用建议**：

- **字体**：宋体，小四号
- **频率**：除非有特殊叙事需要，一般可省略"切至："
- **默认规则**：直接写下一个场景标题即表示"切至"

### **三、特殊元素格式**

#### **1. 蒙太奇序列**

**格式**：

文本

编辑

```
1                    蒙太奇开始
2                    
3内景. 李奇公寓 - 夜
4
5李奇翻看旧照片，神情恍惚。
6
7外景. 街道 - 晨
8
9李奇独自走在空荡的街道上。
10
11内景. 办公室 - 日
12
13李奇机械地处理文件，眼神空洞。
14
15                    蒙太奇结束
```

---

#### **2. 闪回/闪前**

**格式**：

文本

编辑

```
1内景. 李奇公寓 - 夜 - 闪回
2
3（画面色调偏黄，带有怀旧感）
4
5五年前的李奇年轻许多，笑容灿烂。
```

**结束闪回**：

文本

编辑

```
1（画面恢复正常色调）
2
3内景. 李奇公寓 - 夜
```

---

#### **3. 画外音（V.O.）**

**格式**：

文本

编辑

```
1                    李奇（画外音）
2            那天之后，我再也没有见过他。
```

---

### **五、中文剧本格式检查清单**

完成剧本后，请检查以下项目：

- [ ] 场景标题格式统一（内景/外景. 地点 - 时间）
- [ ] 角色名称居中，字体统一
- [ ] 对白居中，左右缩进一致
- [ ] 动作描述使用现在时
- [ ] 避免心理描写，只写可见可听内容
- [ ] 重要角色首次出现时标注特征
- [ ] 页码正确，从正文开始编号
- [ ] 字体统一（宋体/楷体/黑体搭配合理）
- [ ] 行距1.5倍，段落间距适当
- [ ] 标点符号使用全角中文标点
- [ ] 避免过度使用括号备注
- [ ] 转场使用适度
