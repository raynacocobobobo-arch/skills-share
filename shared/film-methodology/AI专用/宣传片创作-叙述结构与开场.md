# 宣传片创作 — 叙述结构与八大开场

> 来源：解说词写作方法论 + 影视综合技巧
> 用途：宣传片技能阶段4（大纲构建）参考

---

## 一、叙述结构四大模型

### 模型 A：时序结构 (Chronological)
- **适用**：历史片、企业成长史、人物传记
- **逻辑**：过去 → 现在 → 未来
- **操作**：将发展历程分为"起步期、发展期、爆发期"三个阶段，每阶段配概括性小标题
- **示例**：《迁徙的人》按7次大迁徙时间排列

### 模型 B：版块结构 (Thematic/Block)
- **适用**：专题片、行业汇报片、政论片
- **逻辑**：大主题切为互不重叠的侧面（如：经济、文化、社会）
- **操作**：拆分3-4个版块，设计过渡句连接
- **示例**："智慧城市" → 智慧交通 / 智慧政务 / 智慧生活

### 模型 C：论证结构 (Argumentative)
- **适用**：深度报道、理论宣传片
- **逻辑**：提出观点 → 列举论据（事实/采访）→ 得出结论
- **操作**：先声明观点，从资料中找正反案例论证
- **核心**：不能只摆事实，必须有逻辑推演

### 模型 D：复调结构 (Polyphonic)
- **适用**：微观纪录片、人物群像
- **逻辑**：多条线索并行，最后汇聚到共同主题
- **操作**：2-3个独立人物/故事，各自展开后在结尾交汇

## 二、八大开场结构详解

### 1. 宏大叙事开场
气势磅礴的开场，用大景别+排比句式建立格局。
- **适用**：大型企业、国家工程、行业龙头
- **技巧**：航拍大全景 + 三句式排比 + 点出时代背景
- **示范**："在XX万平方公里的土地上，XX万人在等待一个答案……"

### 2. 问题悬念开场
先提问题，制造悬念，逐步解答。
- **适用**：技术创新、难题攻关类
- **技巧**：抛出反问句 → 展示困难场景 → 引出解题者
- **示范**："三年了，这口井为什么还没出油？"

### 3. 时间对比开场
过去与现在的强烈反差制造冲击力。
- **适用**：发展变迁、转型升级类
- **技巧**：旧照片/黑白画面 → 跳切到现代画面
- **示范**："四十年前，这里只有一片芦苇荡。"

### 4. 人物出场开场
以一个具体的人切入，从个体映射整体。
- **适用**：企业人文、员工故事类
- **技巧**：特写人物的手/眼睛 → 动作细节 → 揭示身份
- **示范**："凌晨四点，老张的闹钟响了。这是他在这个岗位上的第27年。"

### 5. 口号升华开场
以一句精炼有力的金句开场定调。
- **适用**：品牌片、价值观输出类
- **技巧**：黑屏白字 + 金句 + 渐入画面
- **示范**："有一种力量，看不见，却比钢铁更坚硬。"

### 6. 首尾呼应结构
开场画面在结尾以不同含义重现。
- **适用**：所有类型（通用技法）
- **技巧**：开篇画面在结尾回归，但赋予新含义
- **示例**：开场→一只粗糙的手，结尾→同一只手握住奖杯

### 7. 个体到集体结构
从一个人→一个团队→整个企业的层层递进。
- **适用**：企业形象、团队精神类
- **技巧**：单人特写 → 小组中景 → 全厂航拍

### 8. 双线叙事结构
两条线索平行推进，最后交汇。
- **适用**：技术+人文、产品+用户类
- **技巧**：A线(硬核技术) + B线(人的故事) 交替剪辑，结尾汇合
- **示例**：A线钻头深入岩层，B线工程师深夜推演数据，最后同一口井喷出油流
