# AI Workflow

AI Workflow is the shared methodology layer for designing reliable AI-assisted work.

This is not a tool-specific skill. It captures reusable patterns across models and products.

Sources currently distilled:

- Andrej Karpathy: understanding model capability, context engineering
- OpenAI: decision-first workflow design
- Futurepedia: AI production workflow and knowledge environment
- Matthew Berman: agent role design and repeatable automation
- Anthropic: verification and reliability principles

Excluded:

- Specific product tutorials
- Individual tool usage instructions
- Film-specific production workflows (handled by film methodology)
