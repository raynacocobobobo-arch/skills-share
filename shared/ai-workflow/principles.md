# AI Workflow Principles

## 1. Problem First

Start from the decision or outcome, not the requested format.

Bad:

"Create a report."

Better:

"Help answer this decision question."

## 2. Context First

Complex tasks require a controlled information environment:

Sources
→ Context
→ Analysis
→ Output
→ Review

## 3. Task Mode Selection

Classify the task:

- Thinking: explore, reason, plan
- Execution: perform repeatable work
- Building: create tools or systems

## 4. Agent Role Design

For recurring tasks define:

- Role
- Inputs
- Outputs
- Evaluation criteria
- Iteration loop

## 5. Verification Loop

AI capability does not equal reliability.

Workflow:

Generate
→ Check evidence
→ Review result
→ Human decision
