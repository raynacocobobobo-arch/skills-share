# Hermes Professional Reference Router

本文件负责把 **已经完成 skill 路由的任务** 进一步路由到专业参考书。

它不是新的 skill，也不替代任何 canonical `SKILL.md`。正确顺序始终是：

```text
用户任务
  ↓
web-chatgpt-router / skill-registry
  ↓
canonical SKILL.md
  ↓
本 reference-router（仅当任务需要专业书补充）
  ↓
对应 *.index.md
  ↓
必要时才读取原文对应章节
```

## 核心规则

1. **先读 skill，再查书。** 不允许绕过 canonical `SKILL.md` 直接用参考书生成工作流。
2. **先读 index，再读原文。** `.index.md` 负责判断是否真的需要深读，以及应该读哪一部分。
3. **只按当前问题取书。** 不要因为任务属于“影视”就一次读取全部影视书。
4. **专项索引优先于综合大书。** 例如分镜先读 `影视综合技巧-分镜完整整理.index.md`，不要先加载《影视综合技巧》全文。
5. **原文是最后一层材料。** 只有 index 明确命中、且 skill / bundled references 仍不足时才深读。
6. **参考书是方法来源，不是项目事实来源。** 数字、政策、机构、地点、行业流程、客户信息仍需独立核验。
7. **冲突时以当前任务和 canonical skill 为准。** 参考书不能把 skill 中的可选方法变成强制模板。
8. 用户明确要求“按某本书的方法”时，可以直接读取该书 index，再按需要读原文章节，但仍不得违反当前 skill 的事实、版本和安全规则。

## 1. 写企业 / 品牌 / 产品宣传片文案

**Primary skill:** `hermes-film-宣传片创作`

### 优先索引

1. `电视解说词写作.index.md`
   - 当问题集中在解说词结构、观众意识、句段章法、材料转叙述、声画关系。
2. `导演创作手册.index.md`
   - 当问题集中在主题落地、视觉行动、旁白与画面的二层关系、导演视点。
3. `影视综合技巧.index.md`
   - 当任务同时涉及风格、美术、摄影、声音、剪辑等跨工种设计。
4. `市场营销.index.md`
   - 只有当宣传片问题本质上涉及目标受众、价值主张、定位、品牌或客户收益时加入。

### 不要默认读取

- 故事片 / 编剧书，除非宣传片包含明确剧情化、人物化叙事段落。
- 分镜书，除非交付物已经进入镜头设计。

## 2. 改政府 / 央国企 / 汇报型宣传片

**Primary skill:** `hermes-film-宣传片创作`

### 优先索引

1. `电视解说词写作.index.md`
   - 资料阅读、非虚构主题、叙述结构、观众意识、声画关系。
2. `影视综合技巧.index.md`
   - 把 PPT 式材料转成视听段落；需要纪录片、摄影、剪辑或整体风格判断时使用。
3. `导演创作手册.index.md`
   - 需要从口号 / 概念回到人物、行动、细节、视点和可见画面时使用。

### 必须注意

- 先按 skill 标记和锁定事实，不使用参考书补造数据或成绩。
- 参考书负责“怎么组织和表达”，项目材料负责“事实是什么”。

## 3. 写故事片 / 微电影 / 叙事短片

**Primary skill:** `hermes-film-故事片创作`

### 优先索引

1. `故事片创作.index.md`
   - 短片规模、主角 / 目标 / 阻碍、视觉行动、场景与摄影机动机。
2. `电影编剧创作指南.index.md`
   - 主题、人物、行动线、结构、情节点、场景功能、非线性叙事、系统改写。
3. `导演创作手册.index.md`
   - 节拍、潜台词、导演视点、用动作替代对白、镜头与演员层的深化。
4. `影视综合技巧.index.md`
   - 只有需要风格、纪录片式表演、摄影、美术、声音或剪辑综合补充时使用。

### 选择原则

- “故事太大 / 三分钟装不下” → 先《故事片创作》。
- “结构塌 / 情节点不工作 / 非线性看不懂” → 先《电影编剧创作指南》。
- “场景有结构但拍出来会平 / 太会说不会演” → 加《导演创作手册》。

## 多书路由规则

当多个索引都可能有用时：

1. 先选择 **一个 primary book index** 解决当前最核心问题。
2. 只有出现第二个明确问题时再添加第二本。
3. 一般不同时深读超过两本原文；如果确实需要，先说明每本书分别解决什么问题。
4. 综合大书《影视综合技巧》通常是补充层，不抢占专项书的第一优先级。
5. 同一方法在多本书重复出现时，不需要重复读取。

## 原文深读协议

读取某个 `.index.md` 后，只有满足以下至少一项才进入原文：

- index 的任务表明确命中当前问题；
- canonical skill 与 bundled references 没有足够细节；
- 用户要求按该书的方法分析或写作；
- 需要辨析概念、比较方法，或处理一个具体场景 / 段落 / 镜头；
- 需要验证 index 中的章节定位或补足上下文。

深读时只读相关章节 / 段落，不默认整本加载。

## 跳过参考书的情况

以下任务通常不需要进入本 router：

- 纯格式、文件转换、错别字、排版；
- 已有 skill 和 bundled reference 足够回答的简单任务；
- 事实核验、当前政策、实时市场数据等应使用事实来源的任务；
- 与专业书无关的开发、工具、游戏、生活类 skill。

## 维护规则

新增专业书时：

1. 原文放入 `shared/source-library/专业书/`；
2. 同目录新增 `<书名>.index.md`；
3. index 负责章节 / 主题、适用技能、读取条件和任务映射；
4. 只在本文件增加必要的任务路由，不要把书路径复制进所有 skill；
5. skill 只需要声明 **什么时候进入 Reference Routing**；
6. 修改后按仓库协作规则更新 activity log，并由可运行本地脚本的 agent 执行 repository validation。
