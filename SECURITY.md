# Security Policy

This repository may contain private workflow knowledge. Keep it private unless every included note has been reviewed for publication.

Never commit:

- API keys, bearer tokens, cookies, passwords, Apple app passwords, SSH keys, or cloud credentials.
- Customer scripts, contracts, quotes, contact details, unpublished project files, or private meeting notes unless explicitly cleared.
- Machine-specific absolute paths when a relative path or environment variable can be used.

Use environment variables for live credentials and keep `.env` files out of git.
