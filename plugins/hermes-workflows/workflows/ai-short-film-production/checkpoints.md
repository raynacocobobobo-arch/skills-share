# Checkpoints

Use these checkpoints at phase boundaries. They are gates, not long reports.

## Story Review

Check before `STORY_LOCKED=true`:

- Does the story have a clear but/therefore causality chain?
- Does each major choice result from prior pressure rather than author convenience?
- Is there a hard plot flaw that would break audience belief?
- Is there a third-option problem where the protagonist could solve the conflict more simply?
- Are protagonist desire, conflict, ending, and emotional goal explicit?
- For 1-5 minute shorts, is it one dominant dramatic question rather than a compressed feature film?
- Can visible action replace explanation?

If any answer fails, revise story before visual development.

## Visual Review

Check before `VISUAL_LOCKED=true`:

- Does the world affect the story, not just the background?
- Do large environments change what characters can see, reach, know, or do?
- Are character silhouettes, colors, materials, and identification points stable?
- Is the color system specific enough to prevent drift?
- Are environment rules specific enough to guide prompts?
- Does the visual system support the emotional goal?

If any answer fails, revise visual bible before asset cards or storyboard.

## Production Review

Check before `PRODUCTION_LOCKED=true` and during iteration:

- Does every shot serve story, relationship, information, suspense, setup/payoff, or emotional state?
- Are there filler actions that can be cut?
- Do prompts preserve the locked character and environment rules?
- Is there visible AI drift in character design, color system, materials, or world logic?
- Does montage create a third meaning instead of illustrating dialogue?
- Does the final image carry consequence without extra explanation?

If any answer fails, produce a delta modification plan instead of redesigning the whole project.

## Baseline Review

When the user accepts a direction:

- Record which deliverable became baseline.
- Preserve story lock, visual lock, and production lock unless the user explicitly unlocks them.
- Convert future requests into deltas.

Allowed delta modification examples:

- strengthen the protagonist's visible choice;
- adjust color temperature while preserving the color system;
- replace one weak shot while preserving story order;
- tighten prompts while preserving asset cards.

Disallowed after baseline unless explicitly unlocked:

- new protagonist;
- new ending;
- new core conflict;
- new visual world;
- full prompt rewrite that changes locked assets.
