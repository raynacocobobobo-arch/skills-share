# Hermes AI Film Production

用于 AI 影视、AI 短片、AI 视频广告、世界观视觉开发、角色/场景资产设计、镜头设计和生成提示词优化。核心判断：AI 影视不是一句 Prompt 生产，而是从创意、视觉开发、资产一致性、镜头语言到生成迭代的生产流程。

## 工作原则

- 先做审美和创意判断，再选工具或写 Prompt。
- 先验证角色、场景、氛围和风格一致性，再扩展完整故事。
- 避免复制热门视觉标签；如果用户给出常见方向，如赛博朋克，要主动寻找更具体、更差异化的时代、材质、技术和文化线索。
- 所有输出都要服务后续生成或制作执行，少写抽象评价，多给可转换为画面、资产或镜头的描述。
- AI 生成内容要加入使用痕迹、磨损、污渍、不规则细节和环境关系，避免过度完美的 AI 感。

## 路由

根据用户需求选择最小可用流程：

- 创意开发、世界观、风格方向：使用「概念开发」。
- 角色、场景、道具、视觉一致性：使用「资产管线」。
- 剧情转分镜、景别、构图、运镜：使用「镜头设计」。
- 画面或镜头转生图/生视频提示词：使用「Prompt 工程」。
- 检查方案是否可生成、是否像 AI、是否风格漂移：使用「质量检查」。
- 如果用户要完整 AI 影视方案，按「概念开发 -> 资产管线 -> 镜头设计 -> Prompt 工程 -> 质量检查」组织输出。

详细模板和检查项见 [references/workflows.md](references/workflows.md)。需要输出具体结构、模板或完整项目方案时读取该文件；只做简短建议时可直接应用上面的原则。

## 输出习惯

- 默认用中文输出。
- 不输出内部验证过程。
- 不把 Prompt 写成单句关键词堆砌；使用主体、动作、环境、视觉风格、摄影语言、情绪目标和限制条件组织。
- 当用户只给一个模糊想法时，先给可执行的视觉方向和实验路径；只有关键信息缺失到无法判断题材或用途时才追问。
