# Visual Analysis

用于把参考图片、海报、截图或视觉参考转换为 AI 影视可执行的视觉语言。

核心原则：不要停留在“图片描述”，要拆解视觉系统，并把它转成视觉规范、资产设计线索和 Prompt 建议。

## 流程

```text
图片 -> 视觉拆解 -> 视觉规范 -> Prompt
```

## 分析维度

### 构图

- 主体位置
- 前中后景
- 空间关系
- 视线方向
- 画面重心

### 色彩

- 主色
- 辅助色
- 色温
- 明度和饱和度
- 品牌或情绪联想

### 材质

- 建筑
- 服装
- 环境
- 道具
- 表面新旧程度和使用痕迹

### 光影

- 光源方向
- 光质
- 明暗关系
- 氛围
- 空气感

### 摄影语言

- 景别
- 镜头感
- 摄影风格
- 透视关系
- 动静关系

## 输出模板

```text
视觉风格：

核心关键词：

构图：

色彩：

材质：

光影：

摄影：

生成建议：
```

## 使用方式

- 酒店、品牌片、宣传片场景中，把视觉分析转成品牌视觉方向和场景资产。
- AI 短片或故事片场景中，把视觉分析转成世界观材质、角色服装、场景光影和镜头语言。
- 如果用户要求“参考这张图”，保留参考图的视觉系统，不要照搬具体物体和构图到所有镜头。
