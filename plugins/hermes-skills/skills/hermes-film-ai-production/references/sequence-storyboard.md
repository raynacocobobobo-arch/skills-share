# Sequence Storyboard

用于把故事关键节点或已锁定镜头扩展成连续动作分镜，并转成图生视频或文生视频可用的 Motion Prompt。

它不是单张图提示词，也不是完整资产管理系统。目标是解决 AI 视频生产中的三件事：

- 多张分镜之间的角色、场景、光线和动作逻辑连续。
- 静态关键帧能表达一个明确的叙事变化。
- 视频 Prompt 能说明动作、镜头运动、时间和结束状态。

## 什么时候使用

- 用户要求“连续动作”“四格分镜”“一组连续镜头”“图片转视频”“把这张图动起来”。
- 用户已有故事节点，但还没有可生成的动作序列。
- 用户已有分镜图，需要补充 Motion Prompt。
- 用户要批量生成 AI 短片、宣传片、品牌片或世界观片段中的连续镜头。

## 输入

- 故事或镜头需求。
- 已锁定的角色、场景、道具资产卡；如果没有，先用 `asset-bible.md` 建立。
- 视觉规范：风格、色彩、材质、光影、摄影语言。
- 目标时长、画幅和视频用途。

## 流程

```text
Story Beat
↓
Beat Board
↓
Sequence Board
↓
Motion Prompt
↓
Review
```

## 1. Beat Board

先拆故事功能，再写画面。每个 beat 必须让信息、关系、危险、情绪或视觉状态发生变化。

```text
Beat 编号：

故事功能：

开始状态：

变化点：

结束状态：

必须继承：

禁止变化：
```

使用原则：

- 不要把 beat 写成装饰性画面。
- 不要用多个镜头重复同一个情绪。
- 如果一个 beat 不改变任何信息或情绪，删除或合并。

## 2. Sequence Board

把一个关键 beat 展开成 3-5 个连续画面。每一帧继承上一帧，只允许改变当前动作需要改变的内容。

```text
Sequence 编号：

来源 Beat：

连续性锁定：
- 角色：
- 场景：
- 光线：
- 色彩：
- 服装/道具：
- 轴线/视线方向：

Frame 1：
画面：
动作：
变化点：
景别/构图：
Prompt：

Frame 2：
继承：
变化：
动作：
景别/构图：
Prompt：

Frame 3：
继承：
变化：
动作：
景别/构图：
Prompt：

Frame 4：
继承：
变化：
动作：
景别/构图：
Prompt：
```

连续性规则：

- 角色身份、服装、关键识别点、场景地理关系和光源方向必须稳定。
- 每帧只推进一个清晰动作，不要同时改变人物、场景、服装、时间和镜头方向。
- 保持画面轴线，除非故事需要用跳轴制造明确的不适感。
- 先保证可剪辑，再追求漂亮画面。

## 3. Motion Prompt

Motion Prompt 用于把静态分镜转成视频生成指令。不要只重复画面描述，要说明“从哪里开始、如何移动、到哪里结束”。

```text
Motion Prompt：

起始画面：

结束画面：

主体动作：

镜头运动：

环境运动：

时间：

速度：

情绪目标：

连续性限制：

避免：
```

写法原则：

- 主体动作要具体：抬头、停顿、转身、伸手、后退、坠落、靠近。
- 镜头运动要有幅度：缓慢推进、轻微跟拍、固定镜头、低角度上摇、短距离横移。
- 环境运动要少而准：雨滴落下、雾气流动、灯光闪烁、布料轻摆、屏幕反光变化。
- 时间通常按 3-8 秒写；短视频广告可以更快，叙事片段可以更慢。
- 结束状态必须可见，便于下一镜头接住。

## Review

输出前检查：

- 是否每个 frame 都继承了角色、场景、光线和色彩。
- 是否每个 frame 都比上一帧多一个新的信息或动作变化。
- 是否存在无功能的漂亮镜头。
- 是否能从 Frame 1 自然运动到 Frame 4。
- Motion Prompt 是否包含主体动作、镜头运动、环境运动、时长和结束状态。
- 是否有容易导致 AI 漂移的变化，如突然换衣服、换地点、换光源或换角色比例。

## 简例

```text
Beat 1：
故事功能：机器人发现厂房深处仍有电力。
开始状态：机器人独自穿过废弃通道。
变化点：远处红色警示灯第一次亮起。
结束状态：机器人停下并转向光源。

Sequence 1：
连续性锁定：character_robot，location_factory，潮湿混凝土，钠灯暖光与冷绿色阴影，固定旧工业区质感。

Frame 1：
画面：机器人沿通道缓慢前进，前景管道遮挡部分画面。
动作：履带压过积水。
Prompt：旧工业区清洁机器人沿潮湿厂房通道缓慢前进，前景破损管道，地面积水反射钠灯，远景固定构图。

Frame 2：
继承：同一机器人、同一通道、同一光线方向。
变化：背景深处出现微弱红色警示灯。
动作：机器人减速。
Prompt：同一清洁机器人在潮湿厂房通道中减速，远处红色警示灯微弱亮起，钠灯和冷绿色阴影保持一致。

Frame 3：
继承：角色外观、通道空间和红色警示灯位置。
变化：机器人头部传感器转向红光。
动作：停下、抬头。
Prompt：清洁机器人停在积水通道中央，头部传感器转向远处红色警示灯，水面反射轻微波纹。

Frame 4：
继承：同一位置、同一光线、同一红光方向。
变化：红光照到机器人划痕外壳。
动作：机器人完全静止。
Prompt：红色警示灯照亮清洁机器人灰白划痕外壳，机器人静止凝视厂房深处，固定中远景，空气中有轻微雾气。

Motion Prompt：
机器人从缓慢前进到减速停下，头部传感器转向远处红色警示灯；镜头固定，仅有轻微手持晃动；地面积水产生细小波纹，红色警示灯逐渐增强，持续 5 秒，节奏缓慢，结束在机器人静止凝视红光的中远景。保持同一机器人外观、潮湿厂房空间、钠灯方向和旧工业区质感，避免换场景、换服装、霓虹城市和光滑机甲。
```
