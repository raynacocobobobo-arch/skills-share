# Storyboard Template

用于统一 AI 分镜输出，把剧情、品牌信息或视觉方向转成可生成的镜头描述。

## 镜头模板

```text
镜头编号：

镜头目标：

画面：

主体：

动作：

环境：

景别：

构图：

运镜：

光影：

Prompt：
```

## 使用原则

- 每个镜头必须有主体、动作、环境、景别、构图、运镜和光影。
- 运镜要有叙事动机，不能只写“高级运镜”。
- Prompt 要从镜头字段自然整合，不要堆关键词。
- 多镜头连续时，先引用 `asset-bible.md` 中的角色和场景资产卡，避免角色或场景漂移。

## 简例

```text
镜头编号：shot_001

镜头目标：建立孤独、潮湿、旧工业区的世界观。

画面：清洁机器人穿过废弃厂房通道，地面积水反射钠灯。

主体：character_robot

动作：缓慢前进，履带压过积水。

环境：location_factory，潮湿混凝土、破损管道、低矮天花。

景别：远景

构图：主体在画面下三分之一，前景管道遮挡一部分空间，背景钠灯形成纵深。

运镜：固定镜头，轻微手持晃动。

光影：钠灯暖光和冷绿色阴影混合，空气中有轻微雾气。

Prompt：旧工业区清洁机器人缓慢穿过潮湿混凝土厂房通道，履带压过积水，灰白外壳带橙色维修贴和划痕，远景构图，前景破损管道，背景钠灯形成纵深，固定镜头，轻微手持纪录片质感。
```
