# AI Film Workflows

整体流程：

```text
用户需求 -> Project Start -> Concept Development -> Visual Analysis -> Asset Bible -> Shot Design -> Sequence Storyboard -> Prompt Engineering -> Review
```

## 概念开发

什么时候使用：用户需要世界观、创意方向、风格定位、AI 短片或宣传片的整体方向。

输入：

- 主题、关键词、参考作品、情绪方向、类型、受众、时长、用途。

用于把模糊想法形成完整视觉方向。

处理步骤：

1. 收集灵感来源：电影、摄影、艺术作品、个人兴趣和真实行业资料。
2. 拆解元素：题材、时代、职业、技术、材质、情绪、空间关系。
3. 做差异化定位：把宽泛标签改成更具体的审美系统。
4. 设计视觉实验：用少量关键画面验证角色、场景和氛围是否成立。

输出：

- 核心创意：一句话说明片子的冲突、吸引点或视觉承诺。
- 世界观：时代、空间、技术水平、社会规则、视觉禁区。
- 视觉方向：风格关键词、色彩、材质、光影、摄影质感。
- 差异化定位：说明避开什么常见风格，选择什么更具体的替代方向。
- 视觉实验清单：先测试角色、场景、氛围，再决定故事扩展。

示例：

- “AI 科幻短片”不要直接落到“赛博朋克城市”，可以转成“近未来旧工业区、低成本维修机器人、潮湿混凝土、钠灯、手持纪录片质感”。

## 资产管线

什么时候使用：用户需要连续角色、连续场景、角色/场景/道具 Prompt 或多镜头一致性。

输入：

- 世界观、角色需求、场景需求、道具需求、风格参考。

用于解决 AI 内容一致性问题。

处理步骤：

1. 先确定核心角色、核心场景和关键道具。
2. 为每个核心资产写轻量 Asset Card。
3. 固定颜色、材质、时代线索和禁止变化项。
4. 再把资产规范转换为镜头 Prompt。

输出：

- 角色资产规范：身份、轮廓、服装结构、材质、颜色、损耗细节、表情气质。
- 场景资产规范：地点功能、空间层次、主要材质、时代痕迹、环境光、可复用元素。
- 道具资产规范：用途、结构、交互方式、材质、磨损和识别特征。
- 一致性规则：固定色彩、固定材质、固定时代线索、禁止出现的风格元素。
- 资产 Prompt：角色、场景、道具分开写，便于迭代。

角色 Prompt 结构：

```text
主体 -> 结构 -> 材质 -> 细节 -> 环境 -> 摄影质感
```

真实感增强：

- 加入使用痕迹、污渍、磨损、维修痕迹、不对称细节。
- 让角色和场景有环境关系，不写漂浮在干净背景里的孤立物体。
- 控制高光、皮肤、金属和布料的过度光滑感。

示例：

- `character_robot`：旧工业区清洁机器人，灰白外壳、橙色维修贴、左肩划痕、履带底盘，禁止变成光滑人形机甲。

## 镜头设计

什么时候使用：用户需要分镜、镜头组、AI 视频镜头描述、品牌片或宣传片镜头建议。

输入：

- 剧情、镜头目标、情绪、角色、场景、时长、节奏。

用于把导演语言转换为 AI 可执行描述。

处理步骤：

1. 明确镜头目标和观众情绪。
2. 确定主体、动作、环境和空间关系。
3. 选择景别、构图、运镜和光影。
4. 多镜头或连续动作时，先按 Beat Board 拆故事功能，再用 `sequence-storyboard.md` 展开 Sequence Board。
5. 转成可生成的 Prompt，不只写导演术语。

输出：

- 情绪目标：观众在这个镜头中应该感受到什么。
- 主体动作：什么人在什么环境做什么动作。
- 景别：远景、全景、中景、近景、特写等。
- 构图：主体位置、前中后景、视线方向、空间关系。
- 镜头运动：推近、拉出、跟拍、环绕、固定镜头等，并说明叙事动机。
- 光影：主光方向、明暗关系、色温、空气感。
- 连续动作：Frame 之间继承什么、变化什么、如何接到下一帧。
- 可生成描述：可直接转成图像或视频 Prompt 的镜头描述。

避免只写“震撼”“高级”“电影感”。每个镜头要落到可拍摄或可生成的主体、动作、环境和摄影语言。

连续分镜要求：

- Beat Board 先回答每个叙事节点的故事功能，不直接生成漂亮画面。
- Sequence Board 把关键 beat 展开为 3-5 个连续帧，保持角色、场景、光线、色彩和轴线稳定。
- Motion Prompt 写清起始画面、结束画面、主体动作、镜头运动、环境运动、时长和速度。

示例：

- `shot_001`：固定远景，机器人穿过潮湿厂房通道，前景有破损管道，中景是主体，背景是闪烁钠灯，用拉远揭示空间孤独感。

## Prompt 工程

什么时候使用：用户需要生图、生视频、镜头转 Prompt、Negative Prompt 或迭代建议。

输入：

- 影视需求、镜头设计、资产规范、参考图视觉规范。

参考：[prompt-patterns.md](prompt-patterns.md)，用于把视觉概念拆成 Style Card、结构化描述、生成语言和生产控制路由。

错误方式：

```text
生成一个机器人
```

推荐结构：

```text
主体
动作
环境
视觉风格
摄影语言
情绪目标
限制条件
```

Prompt 输出建议包含：

- 正向 Prompt：完整画面描述。
- Negative Prompt：需要排除的风格漂移、画面错误和 AI 痕迹。
- 迭代建议：下一轮优先调整构图、材质、光影、角色一致性还是动作。

处理步骤：

1. 先明确镜头目标或生成目标。
2. 把视觉概念拆成风格锚点、构图、色彩、材质、光影和摄影语言。
3. 把主体、动作、环境、风格、摄影和情绪分开确认。
4. 判断使用文生图、参考图、图生图、控制图、局部重绘、扩图、图生视频或最终增强。
5. 合并为自然语言 Prompt。
6. 写少量必要 Negative Prompt。
7. 给出下一轮最值得调整的一项。

写法要求：

- 主体和环境要绑定，不写孤立物体。
- 风格要具体到时代、材质、摄影或艺术来源，不堆通用热词。
- 视频 Prompt 要包含起始状态、结束状态、镜头运动和动作连续性。
- 参考图要转成视觉系统，不直接复刻原图、品牌、标语、人物或构图。
- 构图、姿态、深度、局部修复和运动幅度应交给生产控制方式，不强行塞进 Prompt。
- Negative Prompt 不宜泛滥，只排除本项目真正会伤害一致性的内容。

示例：

- 正向 Prompt：旧工业区清洁机器人缓慢穿过潮湿混凝土厂房，履带压过积水，灰白外壳带橙色维修贴和划痕，固定远景，前景破损管道，背景钠灯闪烁，冷绿色阴影，手持纪录片质感。
- Negative Prompt：光滑机甲、赛博霓虹城市、干净展厅、卡通比例、角色外观变化。

## 质量检查

什么时候使用：用户要求审查、优化、判断方案是否可生成，或完整工作流收尾。

输入：

- 创意方向、视觉规范、资产卡、分镜、Prompt。

处理步骤：

1. 先查会导致生成失败或风格漂移的问题。
2. 再查镜头是否有主体、动作、环境和摄影语言。
3. 最后给出下一轮最小修改建议。

输出：

从五个方面检查：

- 创意：是否只是套热门风格，是否有清晰差异化。
- 视觉：角色、场景、道具是否属于同一世界观。
- 资产：关键角色和场景是否有可复用规范。
- 镜头：每个镜头是否有主体、动作、环境、景别、构图、运镜和情绪目标。
- 生成：Prompt 是否结构化，是否包含限制条件和下一轮迭代方向。

发现问题时，按影响生产的程度排序，先修正会导致风格漂移、角色不一致或镜头不可生成的问题。

示例：

- 高优先级：角色每个镜头外观都不稳定，先补 `Character Asset Card`，再写镜头。
- 中优先级：Prompt 有“电影感、高级、震撼”但缺少构图和光影，先补镜头模板字段。
