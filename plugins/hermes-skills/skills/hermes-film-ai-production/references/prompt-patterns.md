# Prompt Patterns

用途：把视觉概念转成结构化描述，再转成可生成语言。

## 核心原则

Prompt 不是关键词堆叠，而是导演意图的结构化表达。

Prompt 负责：

- 故事意图
- 视觉语言
- 主体动作
- 情绪目标

参考图负责：

- 角色一致性
- 构图结构
- 空间关系

控制图负责：

- 姿态
- 深度
- 局部结构

## Prompt 四层结构

1. 意图层

故事目标、镜头目标、观众情绪。

2. 视觉系统层

风格锚点、构图、色彩、材质、光影、摄影语言。

3. 内容层

主体、动作、环境、资产常量。

4. 控制层

参考来源、控制方式、限制条件、下一轮目标。

## Prompt 组装顺序

```text
镜头目标 -> 主体 -> 动作 -> 环境 -> 风格锚点 -> 构图/摄影 -> 色彩/材质 -> 连续性规则 -> 限制条件
```

## Video Prompt 时间结构

图片 Prompt 描述状态。

视频 Prompt 描述变化。

```text
Start State
↓
Motion
↓
Camera Movement
↓
End State
```

视频必须说明：

- 谁在动
- 为什么动
- 如何变化
- 镜头如何观察变化

## Timeline Prompt

视频镜头可以进一步拆分时间阶段：

```text
Start
↓
Action Development
↓
Camera Movement
↓
End State
```

描述：

- 开始状态
- 动作变化过程
- 镜头运动过程
- 最终状态

不要只描述一张静态图片，而要描述镜头如何发生。

## Prompt Iteration

生成不是一次完成。

```text
生成
↓
发现主要问题
↓
只修改一个变量
↓
重新生成
```

问题分类：

- 角色变化：修改 Asset Card。
- 风格漂移：强化视觉锚点。
- 动作错误：增加动作原因。
- 构图错误：优先修改参考图或控制方式。

## 检查

- 是否描述可见视觉特征，而不是空泛词。
- 是否保持资产一致性。
- 是否区分图片状态和视频变化。
- 是否明确下一轮迭代目标。
