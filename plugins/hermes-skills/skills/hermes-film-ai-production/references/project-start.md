# Project Start

用于快速启动 AI 影视项目，特别是用户只有一句模糊需求时，例如“做一个 AI 宣传片”或“我要做一个 AI 科幻短片”。

目标不是追问到所有信息齐全，而是补出足够进入 Concept Development 的项目起点。

## 输入补全

```text
项目类型：
- 宣传片
- 故事片
- 广告
- AI短片

目标：

传播目标：

受众：

参考作品：

情绪：

视觉方向：

必须包含：

避免出现：
```

## 处理步骤

1. 先判断项目类型和用途。
2. 如果信息不足，基于用户原句给出合理假设，并标注“暂定”。
3. 补出传播目标、受众、情绪和视觉方向。
4. 进入 `workflows.md` 的 Concept Development，输出创意方向、世界观、视觉方向、核心资产、镜头方向和 Prompt 策略。

## 输出要求

- 不要只列问题让用户回答。
- 不要直接生成完整影片 Prompt。
- 先给一个可执行的项目启动版方案，再列出最关键的 2-3 个待确认问题。

## 输出骨架

```text
项目启动判断：

暂定需求：

创意方向：

世界观：

视觉方向：

核心资产：

镜头方向：

Prompt策略：

待确认：
```
