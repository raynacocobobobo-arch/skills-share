# Content Creation Workflow

## 定位

该 Skill 负责从目标到内容资产的 AI 辅助创作流程。

不是简单让 AI 生成文字，而是建立：

```
Content Goal
↓
Audience Definition
↓
Context Gathering
↓
Structure Design
↓
Draft Generation
↓
Human Review
↓
Final Asset
```

## AI Workflow Principles

遵循 shared/ai-workflow：

- Problem First
- Context First
- Artifact Driven
- Verification Loop
- Human Review

## 执行流程

### 1. 明确内容目标

确认：

- 内容目的
- 目标受众
- 使用场景
- 成功标准

### 2. 收集上下文

优先使用：

- 品牌资料
- 用户资料
- 历史内容
- 研究资料
- 参考案例

### 3. 内容结构设计

先确定：

- 核心观点
- 信息结构
- 叙事逻辑

再生成正文。

### 4. Draft 与迭代

AI负责：

- 初稿
- 多版本
- 结构优化
- 表达优化

人负责：

- 判断观点
- 确认事实
- 最终编辑

## 输出资产

- Blog Draft
- Article
- Script
- Newsletter
- Social Content
- Content Brief

## 禁止

- 无上下文直接生成内容
- 把 AI 初稿视为最终版本
- 忽略事实验证
