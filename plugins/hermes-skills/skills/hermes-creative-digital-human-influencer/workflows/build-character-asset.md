# Build Character Asset Workflow

## Purpose

Convert a generated character into a reusable digital human asset.

## Required Assets

### Face Identity Pack

- front view
- left 45 degree
- right 45 degree
- profile

### Body Reference

- full body front
- side view
- back view

### Expression Pack

- neutral
- smile
- lifestyle expressions

### Style Profile

- clothing direction
- photography style
- preferred environments

## Completion Criteria

A digital human can enter production only after identity consistency is verified.
