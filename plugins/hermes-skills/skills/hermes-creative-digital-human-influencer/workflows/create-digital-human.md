# Create Digital Human Workflow

## Purpose

Create a new long-term digital human influencer identity.

## Process

1. Define creator positioning

- target audience
- personality
- visual age
- content category

2. Define identity profile

Create:

- face characteristics
- body characteristics
- photography style
- wardrobe direction

3. Generate candidate identity

Evaluate:

- attractiveness
- realism
- consistency potential

4. Select canonical identity

Assign:

`DH-XXX`

5. Enter asset building workflow

The character is not considered production-ready until the identity package is complete.
