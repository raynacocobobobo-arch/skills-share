# Scene Composite Workflow

## Input

- Digital Human Asset
- Environment Image
- Outfit Reference
- Pose Requirement

## Process

1. Analyze environment:

- camera angle
- perspective
- focal length
- lighting
- depth of field

2. Place character:

- scale
- position
- pose
- viewpoint

3. Match reality:

- shadows
- reflections
- color temperature
- image texture

## Quality Check

Reject if:

- character looks pasted
- perspective conflicts
- lighting differs
- identity changes

Goal:

The final image should look like a real photograph taken in the original environment.
