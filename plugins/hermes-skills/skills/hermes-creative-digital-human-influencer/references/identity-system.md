# Digital Human Identity System

## Principle

A digital human is an asset identity, not a single image.

Identity consists of:

- Face
- Body
- Style
- Photography language

## Face Identity

Track:

- face shape
- eye characteristics
- nose structure
- lip shape
- hair
- skin texture

Avoid:

- face drift
- age drift
- random beauty changes

## Body Identity

Track:

- height impression
- body proportions
- posture
- silhouette

## Style Identity

Track:

- clothing direction
- color preference
- camera style
- lifestyle positioning

Every production request should reference the existing identity asset before generation.
