# Asset Lifecycle

## Purpose

Define how a digital human identity asset evolves over time.

A digital human is a maintained production asset, not a disposable generation result.

## Version Model

Every character uses version control:

```
DH-001

v1.0 Initial identity
v1.1 Minor visual refinement
v2.0 Major identity update
```

## Rules

- Never overwrite previous identity versions.
- Preserve successful generations as references.
- Record why a new version was created.
- Keep production outputs linked to the asset version used.

## Change Categories

### Identity Changes

Examples:

- face refinement
- hairstyle update
- age adjustment

Require a new identity version.

### Style Changes

Examples:

- wardrobe direction
- photography style
- creator positioning

May create a style version without changing identity.

## Asset Review

Before upgrading a character version:

- compare face consistency
- compare body proportions
- compare audience positioning
- verify previous content compatibility
