# Character Asset Specification

## Purpose

Define the minimum asset package required for a reusable digital human.

A digital human is treated as a long-term creative asset, not a single generated image.

## Asset Structure

```
Digital Human Asset
├── Character Profile
├── Face Identity Pack
├── Turnaround Sheet
├── Body Reference
├── Expression Pack
├── Wardrobe Library
└── Photography Profile
```

## Required Views

Minimum:

- Front face
- Left 45 degree face
- Right 45 degree face
- Side profile
- Full body front
- Full body side
- Back view

## Identity Rules

The following must remain stable:

- facial structure
- eye shape
- nose structure
- mouth shape
- skin characteristics
- body proportion
- age appearance

Do not regenerate a different person for each scene.
