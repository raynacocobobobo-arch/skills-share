# hermes-creative-digital-human-influencer

## Overview

Create and maintain a consistent AI digital human influencer asset and production workflow.

This skill is designed for long-term character consistency, not one-off image generation.

Core pipeline:

Digital Human Identity
→ Asset Library
→ Scene Analysis
→ Realistic Composite
→ Content Production

## Trigger Conditions

Use when users request:

- digital human creation
- virtual influencer creation
- consistent character generation
- placing a digital human into real environments
- outfit replacement
- social media image production

## Core Rules

1. Identity first.

Never regenerate a new person when an existing digital human asset exists.

2. Maintain consistency.

Preserve:

- facial structure
- age appearance
- body proportions
- style identity

3. Reality matching.

Generated characters must match:

- camera perspective
- lighting
- shadows
- depth of field
- image texture

## Workflows

### Create Digital Human

Create a character identity profile and reference package.

### Build Character Asset

Generate:

- face references
- turnaround views
- style profile
- wardrobe library

### Scene Composite

Combine:

Digital Human Asset
+
Real Environment
+
Outfit Reference

while preserving photographic realism.

### Outfit Transfer

Change clothing while preserving identity.

### Batch Production

Generate multiple social media images from one stable character.

## Quality Standard

Reject outputs with:

- identity drift
- incorrect perspective
- artificial lighting
- floating characters
- obvious AI skin

## Tool Strategy

The workflow is tool-agnostic and can use:

- ChatGPT image generation
- ComfyUI
- InstantID
- IP-Adapter
- ControlNet

The skill defines methodology and quality control, not a single generator.
