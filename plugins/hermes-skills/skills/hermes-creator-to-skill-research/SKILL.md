# Hermes Creator To Skill Research

## Purpose

将创作者素材转化为 Hermes 可复用能力。

输入：
- YouTube 字幕
- 文章
- GitHub 项目
- 教程

输出：
- 创作者工作流分析
- 可复用原则
- Hermes 能力影响
- Codex 修改建议

## Core Rule

不要生成普通视频摘要。

不要整理工具列表。

重点回答：

1. 创作者解决了什么问题？
2. 他实际采用了什么工作流程？
3. 哪些经验可以迁移？
4. Hermes 是否需要变化？

## Workflow

原始素材

↓

提取关键证据

↓

提取创作者工作流

↓

提炼可复用原则

↓

判断 Hermes 影响

↓

生成 Codex 修改建议

## Output Requirements

每次分析必须包含：

- 来源信息
- 关键原文片段
- 工作流拆解
- 方法抽象
- 可复用原则
- Hermes 影响判断
- Codex 任务建议

## Evidence Rule

所有重要结论必须能够追溯到原始素材。

格式：

原文片段：

解释：

提炼原则：

## Boundary

这个 Skill 负责研究和提出修改建议。

不直接修改其他 Skill。

避免过度工程化，只输出能够帮助 Hermes 改进的内容。
