# 营销计划生成器

融合两本经典著作的方法论：
- **Richard Rumelt《好战略，坏战略》**（Good Strategy Bad Strategy）：提供战略内核——诊断→指导方针→连贯行动
- **Philip Kotler《营销管理》**（Marketing Management）：提供营销工具箱——STP、4P/7P/4A、价值链、全方位营销

三层结构对应 Rumelt 的战略内核（Kernel），每个内核要素内部搭载 Kotler 的营销工具。

## 工作流程

### Phase 0：信息收集与确认（必须先做，不可跳过）

#### 步骤 0.1：检索已有信息
- 从 **Memory** 中检索用户业务相关背景（公司、区域、已有业务、资源等）
- 从 **session_search** 检索过往对话中提到的相关客户信息、项目经验
- 从 Obsidian `历史项目/` 目录中检索相关项目记录

#### 步骤 0.2：整理并列出待确认信息
把已掌握和缺失的信息列成清单发给用户确认，格式如下：

```
已知信息（从档案/历史对话中获取）：
- 业务：xxx
- 区域：xxx
- 当前阶段：xxx
- 竞争对手：xxx

需要你确认或补充：
- 预算范围：？
- 时间周期：？
- 团队配置：？
- （其他缺失项）
```

#### 步骤 0.3：等待用户确认
- 用户确认或修改信息后，才开始写方案
- **禁止在用户确认前动笔**
- 禁止用默认值假设然后小字标注"待确认"

### Phase 1：情境诊断（Diagnosis）

> **对应 Rumelt：「What's going on here?」——识别核心挑战，简化复杂现实**

#### 1.1 环境扫描（Kotler 宏观环境）
- **PESTEL 速览**：政策/经济/社会/技术/环境/法律的关键趋势
- **仅提取与用户业务直接相关的因子**，不铺开

#### 1.2 市场与竞争分析（Kotler 5C + SWOT + PESTEL + Rumelt 诊断视角）
- **Company（自身）**：核心竞争力三特征（竞争优势来源/多市场适用/竞争者难模仿）、链环系统最弱一环（Rumelt）
- **Customers（客户）**：五种需求层次（表明了/真实/未表明/令人愉悦/隐秘）→ 不只回应表明了的需求
- **Competitors（竞争对手）**：不对称在哪（Rumelt）；竞争范围要扩大到替代品（Kotler）
- **Collaborators（合作方）**：渠道伙伴、供应商（Kotler：与少而精的增值供应商结盟）
- **Context（环境）**：PESTEL + 变革浪潮方向（Rumelt Dynamism）
- **SWOT**：内部优势劣势 + 外部机会威胁

#### 1.3 核心挑战识别（Rumelt 核心）
- **用一句话提炼核心挑战**：阻碍增长/获客/盈利的最关键障碍是什么？
- 这不是"目标不够高"，而是"为什么过去没做到"
- Kotler 配套检验：营销人员常问的8个问题中去匹配（如何差异化？如何降低获客成本？如何保持忠诚度？）

---

### Phase 2：战略方向（Guiding Policy）

> **对应 Rumelt：选定克服障碍的总体方针，像高速公路护栏一样指引但不定义每一步**

#### 2.1 STP（Kotler）
- **Segmentation（市场细分）**：按什么维度切分市场？（地理/人口/行为/心理）
- **Targeting（目标选择）**：选哪个细分？为什么？  
  - Rumelt 检验：这是聚焦（Focus）的选择吗？还是什么都要？
- **Positioning（定位）**：在这个目标市场里，你要占据什么心智位置？
  - 差异化点（POD）是什么？
  - 价值主张一句话

#### 2.2 力量源泉选择（Rumelt）
从 Rumelt 的 9 大力量源泉中，**明确选择 1-3 个作为战略支点**：

| 力量源泉 | 核心逻辑 | 适用场景 |
|---------|---------|---------|
| **杠杆** | 找到不对称，集中资源在关键点 | 资源有限的小企业 |
| **近期目标** | 选一个够得着的中间目标 | 需要快速证明可行性 |
| **链环系统** | 打造对手难复制的整合系统 | 服务型/体验型业务 |
| **设计** | 精心设计的连贯组合 | 需要差异化时 |
| **聚焦** | 攻击细分市场而非全市场 | 新进入者/小公司 |
| **利用优势** | 找到相对对手的不对称 | 已有某种积累时 |
| **动态** | 抓住行业变革浪潮 | 行业剧变期 |
| **惯性** | 利用对手反应慢 | 大对手是传统企业 |
| **熵** | 利用对手内部混乱 | 对手管理差/方向乱 |

#### 2.3 增长战略（Kotler 安索夫矩阵）
- **密集型成长**：市场渗透 → 市场开发 → 产品开发 → 多样化（按顺序评估）
- **一体化成长**：向后/向前/横向整合
- **多样化成长**：当前产业外的机会

#### 2.4 竞争战略（Kotler）
- 你在 Kotler 竞争谱系中的位置：**市场领导者/挑战者/跟随者/利基者？**
- 对应的战略姿态：防御/进攻/侧翼/游击

### Phase 3：营销组合（Coherent Action）

> **对应 Rumelt：行动必须相互协调、彼此强化，不能是一堆独立清单**

#### 3.1 产品/服务（Product）
- 核心产品是什么？增值服务/体验层是什么？
- 产品如何支撑定位？
- **Rumelt 检验**：这和诊断出的挑战直接相关吗？
- **Kotler 检验**：价值主张（Value Proposition）是否包含顾客价值三元组（质量+服务+价格）？

#### 3.2 定价（Price）
- 定价策略：成本加成/价值定价/竞争定价/渗透/撇脂？
- 价格是否与定位一致？（Kotler：价格应与感知价值良好匹配，否则消费者转向竞争者）
- 付款方式、折扣结构
- **4A 框架检验**：支付能力（Affordability）——目标客户有能力且愿意支付吗？

#### 3.3 渠道/地点（Place）
- 线上/线下渠道；获客路径：客户从哪来？
- 渠道伙伴策略（Kotler：与少而精的增值供应商结盟）
- **4A 框架检验**：可达性（Accessibility）——客户能否方便获取？
- 传播/分销渠道分开考虑（Kotler：传播渠道≠分销渠道）

#### 3.4 推广/传播（Promotion）
- 传播组合：内容营销/社交媒体/广告/公关/活动/直销/人员销售
- 关键信息：一句话传播主张（Kotler：FABV方法——Features/Advantages/Benefits/Value）
- 内容策略和节奏
- **4A 框架检验**：知晓度（Awareness）——目标客户知道你的存在吗？
- 整合营销检验：所有传播接触点是否传递一致的品牌信息？

**视频注意力工程（MrBeast方法论——如果推广涉及视频内容，强制执行）**：

| 维度 | 检查项 | 标准 |
|------|--------|------|
| **CTR（点击）** | 标题结构 | 数字放前4字、删"的""一些"等赘字、制造具体画面而非抽象概念 |
| | 封面 | 人脸放大30%、红色对比色、≤3个视觉元素 |
| **留存（看完）** | 前3秒 | 直接进入内容，禁止自我介绍、"大家好"、铺垫 |
| | 8-15秒 | 闪一下最精彩画面（最终结果/最大冲突/最惊讶反应） |
| | 全程 | 每30-60秒一次pattern interrupt（视角切换/节奏变化/新信息） |
| **概念** | 简单度×极端度 | 一句话说清楚（≤10字）→ 执行做到超预期 |
| **迭代** | 每个视频=A/B测试 | 上线后看CTR+完播率，下周视频改一个变量再测 |

> 核心理念来自MrBeast：视频成功 = CTR × AVD。做任何内容决策前先问——"这会提升CTR还是AVD？如果都不是，为什么要做？"

#### 3.5 人员/流程/方案/绩效（Kotler 现代4P + 服务7P）
- **People（人员）**：团队配置、服务标准。Kotler：将消费者看成人，而非消费产品的购物者
- **Processes（流程）**：客户旅程、服务流程、响应机制（Kotler：避免仅适用单一规划，确保最先进的营销观念在所有方面发挥作用）
- **Programs（方案）**：所有面向顾客的活动整合（旧4P+新营销活动）
- **Performance（绩效）**：财务+非财务指标（盈利性、品牌资产、顾客资产）
- 服务型业务额外补充 **Physical Evidence（有形展示）**：案例展示、作品集、实体触点

#### 3.6 连贯性检验（Rumelt 强制）
- 各项行动之间是否相互强化？还是彼此独立/冲突？
- 如果 A 行动做得好，B 行动会更容易还是更难？

### Phase 4：执行路线图

#### 4.1 时间线
- 分阶段：0-30天 / 30-90天 / 90-180天
- 每个阶段的里程碑

#### 4.2 预算分配
- 按营销组合要素分配
- 优先投入高杠杆环节（Rumelt）
- **Kotler 70/20/10 法则**：70%投入到有把握成功的项目，20%用于改善这些项目，10%用于实验
- 接受实验失败的可能性，但要从中学习

#### 4.3 关键指标（KPI + Kotler 全方位营销绩效）
- 不是列一堆指标，而是**选 3-5 个真正衡量战略进展的核心指标**
- 前导指标 vs 滞后指标
- Kotler 绩效营销四维度：
  - **财务指标**：利润率、ROI、获客成本
  - **品牌资产**：知名度、联想、忠诚度、感知质量
  - **顾客资产**：顾客终身价值、留存率、满意度
  - **社会责任**：法律/伦理/社会/环境绩效

#### 4.4 反馈与迭代（Rumelt：Strategy as Hypothesis）
- 多长时间检视一次？
- 什么信号说明战略对了/错了？（Kotler：需要反馈和控制来了解营销活动效率和效益）
- 调整机制（Kotler：制定能经受时间考验的战略，但不断改进它——规范性和灵活性的结合）

## 原则

1. **诊断先于方案**：搞清楚"为什么过去没做到"再谈"怎么做"
2. **取舍 > 叠加**：好的营销计划是减法，不是什么都做
3. **连贯性检验**：每项行动都要问"它和别的行动是互相强化还是彼此抵消"
4. **保持通用**：技能不含具体公司信息，公司信息由用户提供
5. **输出到桌面**：营销方案保存到 `~/Desktop/hermes/营销/` 目录
6. **自动生成执行看板**：方案用户确认后，立即在同目录生成 `[项目名]_执行看板.md`（详见 Phase 5），不再单独询问

#### 看板规则
1. **每个营销行动都拆成可执行的具体任务**，而非模糊描述
2. **每个任务有负责人**（如果用户未提供则标注"待分配"）
3. **每个阶段不超过 5-7 个并行任务**（Rumelt：聚焦）
4. **假设验证表**：把方案中的核心假设写进去，绿灯=验证通过，红灯=需要调整
5. **周度复盘记录预置 4 行空模板**，便于后续填入
