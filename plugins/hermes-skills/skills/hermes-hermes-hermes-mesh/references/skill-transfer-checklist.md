# 技能跨节点传输 Checklist

向另一 Hermes 实例（企微/云端）发送技能前，逐项检查：

## 发送前检查

- [ ] SKILL.md 不为空（常见问题：迁移后只剩几行路径修正）
- [ ] 无 OpenClaw 专用依赖（`from openclaw import`、`word-reader` 等）
- [ ] 路径不含 Mac 专属路径（`/Users/rayna/`、`~/Desktop/`）——改为环境判断或通用路径
- [ ] 技能引用本地 Obsidian 文件时，标注"如该文件不在你服务器上，向用户索取"
- [ ] 支持文件（textbank、scripts、templates）一并打包

## 传输协议

- 单文件 ≤150KB：直接 base64 嵌入消息体
- 多文件/超大：`tar -czf` → base64 → 一段发送（注意 60 秒间隔避免同名覆盖）
- 解压路径使用对方路由表中的路径（见企微路由表）

## 委托指令原则

- ✅ "安装并根据你的实际情况优化" 
- ❌ "把触发词改成XX""输出格式用YY""你的用户肯定是ZZ"——不了解对方业务环境时不应替对方做优化决策
