# 影视创作场景下的女娲蒸馏应用

> 基于 nuwa-skill 方法论，针对宣传片/故事片/分镜导演工作的具体落地。

## 场景 1：蒸馏导演风格，辅助分镜创作

**痛点**：客户说"我要王家卫的感觉"或"参考张艺谋的视觉"，但导演本人无法24小时在线提供判断。

**做法**：
1. 用女娲蒸馏该导演（著作/访谈/拉片分析/影评人批评/创作手记）
2. 蒸馏出的 skill 包含：视觉偏好、节奏感、配色倾向、镜头语言、常用隐喻、绝不用什么
3. 出分镜时调出来："用王家卫的视角审查这份分镜，指出不符合他风格的段落"

**6维度调研在影视领域的适配**：

| 维度 | 影视导演对应 |
|------|-----------|
| 著作与系统思考 | 创作手记、导演阐述、自传、北电/中戏教材引用 |
| 对话与即兴思考 | 映后谈、大师班、电影节采访、片场花絮 |
| 表达DNA | 镜头语言习惯（长镜/手持/固定）、色彩板、常用意象、节奏 |
| 他者视角 | 影评人分析、同行评价、豆瓣/IMDb影评、争议作评价 |
| 决策记录 | 为什么选这个剧本、为什么换演员、为什么改结局 |
| 时间线 | 不同时期风格演变（早期→转型→成熟） |

## 场景 2：蒸馏甲方/客户审美偏好

**痛点**：客户说不清楚要什么，反复改稿。

**做法**：
1. 收集该客户过往所有项目的反馈记录、修改意见、通过的方案
2. 蒸馏成"甲方审美 skill"——他喜欢什么色调、讨厌什么镜头、对节奏的容忍度、决策时最在意什么
3. 下次出方案前先过一遍 skill，减少无效修改

**关键**：蒸馏甲方的"什么不做"比"喜欢什么"更有价值——拒绝过的方案比通过过的方案更有信息量。

## 场景 3：蒸馏标杆宣传片

**痛点**：客户给的参考片只是"感觉"，难以转化为可执行的镜头语言。

**做法**：蒸馏一个"宣传片类型 skill"（主题蒸馏而非人物蒸馏）：
- 该类型宣传片的共性框架（节奏、情绪曲线、信息密度）
- 各成功案例的分歧点（A偏纪实/B偏写意/C偏科技感）
- 受众心理预期

## 场景 4：策划阶段的多视角审查

蒸馏 3 个不同视角的"顾问"：
- 一个极端商业导向（广告转化率优先）
- 一个极致艺术导向（视觉冲击优先）
- 一个甲方导向（预算和deadline优先）

出方案后三者并行审查 → 综合三方意见 → 方案天然多视角。

## 快速启动

说"蒸馏张艺谋"或"蒸馏一个宣传片大师"即可触发女娲全流程。
蒸馏完成后说"用张艺谋的视角看这个分镜"即可调用。
