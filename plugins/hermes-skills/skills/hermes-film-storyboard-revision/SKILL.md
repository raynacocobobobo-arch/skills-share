# storyboard-revision 分镜修正技能 v1.1.0

核心思想：**前置检校**。在写分镜之前就把资料查清楚、偏差标出来、二次验证做完，直接输出矫正过的石化分镜稿。

## 能否单独使用

✅ 可独立使用。已嵌入石化分镜的核心输出格式（文案/画面/声音/特效分离）、六大规则、叙事映射库、禁用清单。加载这一个技能就能直接输出石化分镜格式的矫正分镜，不需要额外加载石化简易分镜。

---

## 核心工作流

### 第0步：客户对齐（必须先做！）

跟客户确认以下信息，输出简表给客户确认，**不直接给完整分镜**：

1. 几个场地？
2. 每个场地什么工作流程？
3. 每个流程需要几个人、什么道具？

**输出格式（客户确认表）** ：
```
| 场地编号 | 场地名称 | 工作流程 | 需要人数 | 道具 |
|---------|---------|---------|---------|------|
| 1 | XX | XX | X人 | XX |
```

### 第0+步：判断拍摄类型

根据场地和内容判断拍摄类型，决定视觉要素：

| 类型 | 特征 | 关键镜头 | 避免 |
|------|------|---------|------|
| 生产型 | 设备运转、值班巡检 | 设备运行特写、员工操作 | 假施工 |
| 建设型 | 脚手架、焊花、吊装 | 施工现场航拍、进度对比 | 摆拍 |
| 展陈型 | 展示板、沙盘、荣誉墙 | 参观讲解、资料翻阅 | 空镜过多 |
| 综合型 | 以上混合 | 按场地切类型 | 风格不统一 |

### 第1步：查主体信息（并行搜索）

提取排期表中每个地点名，执行并行搜索：

1. **设施信息**：搜索"XX是什么设施？已建成还是在建？有什么特色亮点？"
2. **历史案例**：用 `session_search` 查该地点/类似项目是否拍过，当初踩过什么坑
3. **数据验证**：排期表中的数字（产量、人数、面积）是否合理

### 第2步：辨别差异（逐项审查）

将排期表内容与查到的真实信息逐项对比，标注：

- ✅ **合理**：信息匹配，直接采用
- ⚠️ **可修正**：描述不准确但可改，给出修正方案
- ❌ **不存在**：排期表写了但现场根本没有的东西，标红退回

### 第3步：矫正分镜输出

🔴 **不是套格式壳子——必须对标内嵌的石化分镜六大规则：**

在写每个镜头时，同时应用：
- 规则① 认知负荷：每个场景第一个镜头必须是环境全景
- 规则② 可执行性：画面写具体动作+环境+运镜（推近/横移/俯拍/弧形轨道）
- 规则③ 情绪呼吸：每10-15镜插呼吸镜头
- 规则④ 视觉母题：设计开场→结尾闭环
- 规则⑤ 真实优先：特效≤20%
- 规则⑥ 格式：画面后独立备注行

**HSE：有人员的镜头，画面描述中直接写"宝石花安全帽（下颚带扣紧）+红工装"，不只在备注提。**

基于查证事实+差异分析，直接输出矫正分镜。格式标准：

```
【镜头 XX】
文案：[客户提供了才填，否则写"(待客户提供文案)"]
画面：[人在什么环境做什么动作，运镜方式]
声音：[环境同期声+音乐]
特效：[文字标注 / 叠印，≤20%]
```

### 第4步：二次验证（内置质检）

逐镜反查，标注置信度。**在此步骤强制加载并逐条对标石化分镜六大规则：**

| 规则 | 验证 |
|------|------|
| ①认知负荷 | 每个场景第一镜是环境全景吗？ |
| ②可执行性 | 每镜有具体动作+运镜词汇吗？ |
| ③情绪呼吸 | 有呼吸镜头穿插吗？ |
| ④视觉母题 | 开场结尾有呼应吗？ |
| ⑤真实优先 | 真实场景≥80%吗？ |
| ⑥格式 | 画面后有备注行吗？ |
| HSE | 画面里写安全帽+工装了吗（不是备注）？ |

置信度标记：

| 标记 | 含义 |
|------|------|
| ✅ | 有资料佐证，放心拍 |
| ⚠️ | 需现场确认，到场地先核实 |
| ❌ | 存疑退回，不走拍摄流程 |

## 🔴 关键规则（严禁违反）

### 规则A：严禁跳过第0步
- **必须先出客户确认表，再出分镜。** 哪怕用户说"直接跑"，也必须先输出简表确认场地/流程/人数/道具。
- 跳过第0步直接出完整分镜 = 必然返工。

### 规则B：严禁自编旁白文案
- 客户没提供文案栏写 `(待客户提供文案)`
- 排期表「解说文案」列有内容才引用，没有就空着

### 规则C：内嵌石化分镜必须逐条应用，不是"格式套壳"
以下六项必须在每个镜头中可查验，不能只写在SKILL.md里：
- ① 认知负荷：每个场景第一镜 = 环境建立（空镜/全景），不直接切动作
- ② 可执行性：每镜有具体动作 + 具体运镜方式（推近/拉出/横移/俯拍/跟拍/弧形轨道），不用"中景拍摄"这种笼统描述
- ③ 情绪呼吸：每10-15镜一个呼吸镜头（空镜），转场独立成镜
- ④ 视觉母题：开场→结尾形成呼应闭环
- ⑤ 真实优先：先有真实场景再考虑特效，特效≤20%
- ⑥ HSE红线：有人物的镜头，画面描述里写"佩戴宝石花安全帽（下颚带扣紧）+ 标准红工装"，不是只放在备注里

### 规则D：禁用清单
- **抽象词**：神秘感、数据流动、跨越感、引领姿态、开拓者姿态
- **个例**：长城、灯塔、军号、国旗、战鼓、心跳声、日历翻页
- **工业八股文**：每镜必有粒子、特效饱和
- **笼统运镜**：❌"中景拍摄" → ✅"中景跟拍，镜头跟随人物转身，从工位横移到门口"
