# 宣传片创作 — 受众适配与改稿模式

> 用途：宣传片任务中涉及既有稿件修改、政府/企业汇报、招商推介、产品介绍、时长压缩、数据取舍、多来源口径冲突时使用。
> 核心原则：先识别任务条件，再选择结构、数据密度和修辞强度；不要让固定方法论反过来支配项目。

---

## 一、先判任务模式，再决定流程

任何宣传片任务先归入以下模式之一：

| 模式 | 可观察条件 | 默认动作 |
|---|---|---|
| A 从零创作 | 只有 Brief / 素材，没有成型结构或正文 | 走完整六阶段 |
| B 结构重构 | 已有稿件，但用户明确要求推翻结构 / 重新搭大纲 | 保留事实资产，重走阶段1/2/4/5 |
| C 基于现稿改稿 | 用户说“在这个版本上改”“保留结构优化”“不要重写” | 先建立原稿基线，只改必须改变的部分 |
| D 局部润色 | 用户指定某段、某句、某章优化 | 不扩大范围，不自动重构全文 |
| E 既有 Word 原文件修改 | 用户上传 Word 并要求直接在此基础上改 | `宣传片创作` 管内容判断，`doc-reviewer` 管文件保真与落盘 |

### C/D/E 模式的“原稿基线”

开始写之前必须先列清：

1. **必须保留**：用户已确认的结构、段落、事实、标题、口径、句子。
2. **必须修改**：会议意见、客户新要求、用户明确不满意处。
3. **可优化**：不影响方向的措辞、节奏、过渡、信息密度。
4. **禁止擅改**：用户未授权重构的章节顺序、核心定位、已锁定事实。

修改原则：**最小必要改动优先于“重新写一版更漂亮的”。**

## 二、受众 / 使用场景决定表达策略

| 场景 | 观众首先需要 | 结构倾向 | 数据策略 | 文风 |
|---|---|---|---|---|
| 政府领导 / 正式汇报 | 主体是谁、规模多大、做成什么、产业价值 | 总—分—总 / 版块结构 | 核心数据应让观众“听见”；细参放字幕 | 直接、正式、稳健、少虚词 |
| 企业品牌形象 | 记住品牌气质与核心价值 | 主题/情绪/人物/视觉母题 | 数据从简，关键事实保留 | 凝练、形象、可有文学性 |
| 招商 / 投资推介 | 能力、收益逻辑、证据、确定性 | 论证 / 总—分—总 | 成果、规模、产能、客户等关键数据可口播 | 商业逻辑清楚、证据导向 |
| 产品 / 技术介绍 | 功能、差异、使用收益、可信证据 | 问题→能力→结果 | 关键性能可口播，次级参数做包装 | 准确、易懂、少空泛概念 |
| 人物 / 文化品牌 | 情绪、人物、价值观 | 人物/时序/复调 | 数字仅在有叙事意义时口播 | 克制、有画面、允许留白 |

### 冲突处理

结构与风格优先级：

**用户/客户明确要求 > 播放场景与受众 > 项目素材自身逻辑 > Hermes 默认结构/修辞模板。**

如果客户已经明确“传统企业宣传片、开门见山、总分总”，不要为了创意强行改成行业痛点开场、悬念开场或文学开场。

## 三、旁白与字幕：按“记忆优先级”分工，不按“事实/情感”绝对分家

### 一级事实：必须听见

满足任一条件，允许且通常应进入旁白：

- 决定主体规模或行业位置的数字；
- 直接证明成果、增长、产能、覆盖范围的数据；
- 观众只听声音也必须知道的信息；
- 会议/客户明确要求口播的数据；
- 不说出来就无法完成核心论证的事实。

### 二级事实：适合字幕 / 包装

- 设备型号、规格、详细配置；
- 次级荣誉全称；
- 多个相近参数；
- 具体职务头衔；
- 说出来会明显拖慢理解但画面可读的信息。

### 三级事实：可删除

- 对核心认知没有影响；
- 与其他事实重复；
- 只是资料齐全但不承担论证作用。

**禁止机械执行“旁白不能出现数字”。**真正的检查是：这条信息是否值得占用听觉带宽。

## 四、多来源资料的权威与状态

### 权威优先级

1. 用户当前回合明确确认 / 修正；
2. 客户已确认口径、正式定稿或明确修改意见；
3. 会议决议 / 修改纪要；
4. 最新正式数据表、制度文件、事实材料；
5. 原脚本 / 历史文案；
6. Hermes 方法论和通用创作经验。

**方法论不能推翻已经确认的项目事实；它只能帮助更好表达事实。**

### 每条关键事实标状态

- `LOCKED`：用户/客户已明确确认，后续不反复质疑，除非出现新的直接冲突证据。
- `CONFIRMED`：有正式资料支持，可使用。
- `TENTATIVE`：有资料但仍需确认，谨慎使用或标注待确认。
- `CONFLICT`：来源互相冲突，不能自行选一个；需按权威优先级处理或向用户说明。

建议论据矩阵增加：`Source / Status / Priority / Channel` 四列。

## 五、时长不是最后压字数：大纲阶段先做信息预算

先确定：

1. 总时长目标；
2. 预计旁白字数区间；
3. 每章秒数；
4. 每章唯一核心认知；
5. 每章最多几个口播数据；
6. 哪些事实移到字幕 / 包装。

### 三档信息取舍

- **A 必须听懂** → 旁白。
- **B 必须看见，不必听完** → 字幕 / 数据包装。
- **C 有资料，但不改变核心认知** → 删除。

如果出现“每个数据都重要、每个板块都要讲、时长还要缩短”，先做取舍，不要用加快语速和缩短字幕停留时间解决结构问题。

## 六、改稿时的段落检查

每段只回答一个主要问题：

- 观众看完这段应该**知道什么**？
- 这段用什么**事实/行为/数据**证明？
- 它与上一段相比推进了哪一步认知？

如果只是“过渡、气势、升华”而没有新增认知或情绪作用，删掉或并入邻段。

---

## 七、正式语言 ≠ 套话；抽象词要看是否携带产业关系

### 优先删除

换任何企业名都成立、没有具体关系的句子，例如：

- 赋能未来；
- 共启新篇；
- 激发新动能；
- 构筑新格局；
- 汇聚磅礴力量。

### 可以保留

虽然书面，但确实表达行业关系、组织变化、价值链位置的词，例如：

- 一体化协同；
- 流通组织方式；
- 产业链延伸；
- 资源整合；
- 加工制造；
- 供应链协同。

判断问题：**删掉这个术语后，具体业务关系是否丢失？**

---

## 八、记忆句 / 金句：认知效率优先于修辞密度

金句不是硬指标。优先写“记忆句 / 判断句”：它应至少完成一种功能：

- 压缩核心事实；
- 完成价值判断；
- 完成结构转折；
- 把复杂业务变成一听就懂的关系。

### 伪金句检测

出现任一情况，优先重写：

- 只因为对仗所以存在；
- 换成任何企业名称仍成立；
- “不是A而是B”只是在解释策划逻辑；
- “如果说A那么B”只是把提案逻辑念给观众；
- 抽象名词明显多于实体和动作；
- 删除后信息、情绪和节奏都不受损。

好的记忆句要能回答：**为什么只有这个项目、这段事实能说这句话？**

---

## 九、既有 Word 的跨技能衔接

当用户要求“在这个 Word 上改 / 在这个版本基础上改 / 保留结构直接修改”：

1. `宣传片创作` 仍是内容专业主技能，负责判断改什么、保留什么。
2. **REQUIRED SUPPORTING SKILL:** `doc-reviewer`，负责在原文件副本中保留段落、标题、表格和格式。
3. 净稿模式也必须以原文件副本为基础替换内容；不能重新创建一份“内容类似”的 Word 冒充基于原稿修改。
4. 只有用户明确要求“重新排版 / 重做文档 / 新建一版”时，才允许从空白文档重建。
