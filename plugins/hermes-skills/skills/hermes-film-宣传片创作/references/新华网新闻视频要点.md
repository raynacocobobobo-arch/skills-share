# 新华网新闻视频方案策划要点

> 来源：2026-06-05 扬子江药业安全管理制度新闻视频策划
> 更新：2026-06-05 新增政策锚定客观性校验

## 定位
- 不是企业宣传片，是**制度创新样本**报道
- 核心标准：制度创新、行业示范、可推广性
- 不煽情、不虚构、不用人物故事驱动

## 内容方向优先级
1. 制度创新样本（某项制度解决了行业什么痛点）
2. 政策落地样本（企业做法如何对应国家政策部署）
3. 安全管理现代化转型（从经验管理到制度管理、从行政推动到全员参与）

## 政策锚定方法
- 先查当前最新国家政策文件（安全生产治本攻坚三年行动、当年安全生产月主题等）
- 用原文中的制度逐条对应政策条文
- 落点在"企业对政策的制度化响应"，而非企业自说自话

### 政策匹配客观性校验（强制）
- 逐条评估每个制度与政策的对应是否**真实同频**，而非硬贴
- 表述用"为政策落地提供了企业样本""与政策方向一致"，**禁用**"←→"式机械一一对应
- 如果某项制度确实超出政策最低要求（如"无脚本演练"比政策说的"至少1次演练"更严格），表述为"走在了政策前面"而非"响应政策"
- 政策原文中不存在的词汇（如"SCL表"）不能直接说"对应第X条"，应说"做法为第X条提供了落地样本"
- 明确区分：方向一致（可以写）vs 硬贴标签（不能写）

### 可结合的政策层级
- **第一层（最瓷实）**：具体法律条文（新《安全生产法》第4条）和国务院文件（三年行动方案具体条款）
- **第二层（可点缀）**：年度主题（安全生产月主题）
- **第三层（慎用）**：总书记论述（指导思想层面，点到为止，不宜大段引用）和五年规划（具体条款少，适合做背景）

## 避免的做法
- 人物故事驱动（不是新华网制度报道的路子）
- 过度渲染/抒情
- 虚构场景、对话、人物细节
- 机械的"←→"政策对应
- 未经校验就说某制度"响应"某项政策
- 材料拆解时默认用一句话概括每项，**用户没要求时不要上表格**（即使觉得表格更清晰也不要自行决定）

## 常用政策文件速查（安全生产/绿色制造类）

### 政策搜索技术备忘
- 当 `web_search` 不可用时，使用 `tavily-search` skill 的 curl 方式直接调 Tavily API
- 搜索关键词模板：`[政策主题] [年份] 国务院/应急管理部 文件`
- 优先搜应急管理部官网（mem.gov.cn），政策原文最权威
