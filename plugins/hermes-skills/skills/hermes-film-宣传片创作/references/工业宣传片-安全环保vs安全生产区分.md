# 工业/药企宣传片：安全环保 vs 安全生产 的区分

## 问题

客户说"做安全方面的片子"时，实际可能指两种完全不同的事：

| 客户说的 | 客户实际要的 | 区别 |
|---------|------------|------|
| "安全生产" | 安全生产（窄） | 只工作场所安全：隐患上报、SCL表、应急演练、安全月 |
| "安全" / "安全环保" | 安全环保（宽） | 安全 + 环境保护 双轨：安全生产 + 废水废气固废治理 + 绿色低碳 + 无废工厂 + 碳达峰 |

## 扬子江药业案例

**废稿问题**：三个方向全部聚焦在"安全生产"（文化培育/隐患上报/演练），客户打回。

**客户实际要的**："安全环保"双线——
- 安全线：体系管理、危险源管控、应急、职业健康（零事故/零伤亡）
- 环保线：废水治理（COD≤150mg/L）、废气治理（RTO）、固废危废（无废集团）、光伏（30MW）、碳达峰2030

**关键纠正**："安全环保"是一个词，不是一个部门+另一个部门。证据：SHE中心统一管、同一套应急预案覆盖废水超标排放、同一套审计同时查安全和环保。

**完整案例**：见 `references/扬子江药业-安全环保案例.md`

**教训**：药企/化工厂的"安全"几乎必然包含环保。听到"安全"先确认是窄义还是广义。

## 区分信号

| 信号 | 倾向 |
|------|------|
| 客户素材里有排污数据、绿色工厂、光伏、双碳 | → 安全环保（宽） |
| 客户素材只有SCL表、演练、未遂事件 | → 安全生产（窄） |
| 客户说"安全环保中心/SHE中心" | → 必含环保 |
| 客户是药企/化工/制造 | → 大概率含环保 |

## 处理流程

1. 拿到素材后，先搜：有没有"废水/废气/固废/绿色/碳"关键词？
2. 有→跟客户确认：是只做安全生产，还是安全+环保都做？
3. 得到确认后再定方案方向，避免全废稿重来。
