# 宣传片创作全流程引擎

## 全局硬性约束

### 旁白与字幕信息分层原则
- 旁白 = 外壳：传递精神面貌、情感、画面感（"你应该感受什么"）
- 字幕 = 内核：承载数据、荣誉、具体事迹（"你应该记住什么"）
- 两者互补，不重叠
- 旁白中禁止：具体数字型号（180/380）、具体荣誉全称、具体工具名称、具体职务头衔
- 写作顺序：先写字幕（把所有事实全列上）→ 再写旁白（只答：这个人给观众什么感觉？）→ 最后校验

### 素材真实性（全局硬约束）
- 严格只使用用户提供的素材/原文，禁止添加素材中没有的场景、人物、细节、对话、数字
- 分镜的画面建议、文案的场景描写，都只能引用素材中明确提到的内容，不虚构
- 如用户反馈"不要捏造"，立即逐条回溯——每个论断、每个画面描述在素材中是否有依据
- 这是用户多次纠正过的红线

### 方向确认优先原则
- 当用户说"给我几个方案/方向"：只输出方向概述（每个方向2-3句核心逻辑），不输出完整结构/分镜/文案/分镜纲要
- 用户选择方向后再展开细节。避免用户反复纠正"不用写整体结构""不要用表格"
- 素材拆解类任务：优先用简洁的一句话概括每项，用户没要求时不上表格。用户说过"材料拆解不要用表格，给我一句话吧"——这是对表格的明确反感，即使你觉得表格更清晰也不要自作主张
- 不要求全覆盖：用户说"其实可以不用所有的都展现"时，不必覆盖全部素材，聚焦用户指定的板块即可

### 专业性原则
好 Agent 不是"快速给结果"，是"准确执行流程"。不急于给结论，严格执行阶段流程。

## 项目文件架构（两级，简化为 Hermes 适配）

每个新项目在 `~/Desktop/hermes/宣传片/[项目名]/` 下创建：

### 文件体系
| 文件 | 格式 | 用途 |
|------|------|------|
| `[项目名].md` | Markdown | **项目记忆文件** — 状态索引+关键变量+版本历史+关键决策 |
| `[项目名]S[N]V[M].md` | Markdown | **阶段Archive** — 每阶段的完整创作产物（论据矩阵/大纲/文案） |
| `[项目名]-文案.docx` | DOCX | **最终交付** — 人类阅读的排版文件 |

### 项目记忆文件模板（新项目第一步创建）
```
# [项目全称]
- 创建时间: YYYY-MM-DD
- 最后更新: YYYY-MM-DD
- 当前阶段: 阶段1（需求确认）
- 项目简称: [2-4字]
- 客户: [甲方名称]
- 影片类型: 宣传片

## 核心变量
（阶段1完成后填入：核心卖点、目标受众、影片调性等）

## 版本历史
（每完成一个阶段追加）

## 关键决策
（记录每个阶段的重要决策和原因）

## 创意资产
（记录确定的旁白风格、视觉基调、主持人策略等）
```

### 命名规则
- 项目简称：2-4个汉字或字母（如"内蒙"、"华北石化"、"HS"）
- 阶段号：1-6
- 版本号：V1、V2、V3...（每次修改递增）
- 示例：`内蒙S4V1.md`、`华北石化S5V2.md`

## 六阶段创作流程

### 阶段 1：客户需求确认与结构化变量生成

**目标**：将客户原始需求转化为结构化创作变量。

**输入**：
- 用户提供的客户需求/Brief/背景资料
- 如有文件，用 `read_file` 读取

**核心分析**：第一性原理分析 — 这个片子真正要解决什么问题？
- 说服目标 4 问：观众是谁？现状是什么？目标是什么？障碍是什么？
- 核心卖点提炼
- 影片调性判断

**费曼检验（强制）**：输出结构化变量前，执行2项检查——

1. **一句话检验**：把这部片子的核心用一句话（≤30字）说清楚。如果说不清楚=没真理解客户需求，回到说服4问重新梳理。
2. **命名≠理解检测**：变量清单里有没有术语在充数？（如"提升品牌形象"——具体是提升哪方面的认知？用什么让人记住？）每个抽象词必须能翻译成具体画面。

**⚠️ 工业/药企项目：安全环保≠安全生产（强制检查）**：
客户说"做安全方面的片子"时，先读 `references/工业宣传片-安全环保vs安全生产区分.md`。检查素材中是否有废水/废气/固废/绿色/碳等环保关键词——有则几乎必然是"安全环保"双线，不是窄义的"安全生产"。在方案方向确认前跟客户确认。扬子江药业废稿即为本案教训。

**输出**：
1. 结构化变量清单（核心卖点、目标受众、影片调性、时长预估等）+ 费曼检验结果
2. 写入 `[项目名].md`（项目记忆文件）
3. 写入 `[项目名]S1V1.md`（阶段1完整Archive）

**验证**：给用户确认核心卖点和调性是否正确。

---

### 阶段 2：素材深度认知与论据矩阵

**目标**：将客户提供的所有素材转化为可用的创作原料。

**启动时**：
- 先读 `[项目名].md` 获取项目上下文
- 读 `[项目名]S1V1.md` 获取阶段1产物
- 如有客户提供的文件，用 `read_file` 读取

**论据矩阵系统**（6类论据，完整填写）：

| 表号 | 论据类型 | 内容 |
|------|---------|------|
| 表1 | 数据论据 | 产量、产值、规模、增长率等量化数据 |
| 表2 | 案例论据 | 标杆项目、获奖情况、典型事迹 |
| 表3 | 人物论据 | 关键人物、典型员工、团队故事 |
| 表4 | 行为论据 | 具体操作、工艺流程、现场场景 |
| 表5 | 情感论据 | 感人故事、情感纽带、人文关怀 |
| 表6 | 历史厚度论据 | 发展历程、里程碑、传承 |

**技法标注**：此阶段调用 `content-tagger` 技能提取修辞技法标注。

**输出**：
1. 完整的论据矩阵（表1-6）
2. 写入 `[项目名]S2V1.md`
3. 更新 `[项目名].md`（当前阶段→3，追加版本历史）

---

### 阶段 3：创意方向参考（可选）

**目标**：搜索市场案例，提供创意方向参考。

**启动时**：读 `[项目名].md` + `[项目名]S2V1.md`

**执行**：
- 用 `web_search` 搜索同行业/同类型宣传片案例
- 分析竞品创意方向
- 提出2-3个创意方向供选择

**输出**：
1. 创意方向分析报告
2. 写入 `[项目名]S3V1.md`
3. 更新 `[项目名].md`

---

### 阶段 4：叙述结构设计与文案大纲构建

**启动时**：读 `[项目名].md` + `[项目名]S1V1.md` + `[项目名]S2V1.md`

**核心框架**：
- **四段式逻辑**：有没有 → 能不能 → 稳不稳 → 值不值
- **8大核心结构**：宏大叙事开场/问题悬念开场/时间对比开场/人物出场开场/口号升华/首尾呼应/个体到集体/双线叙事
- **26种技法**：排比、对偶、比喻、拟人、古风、抒情散文、数据化说理等
- **说服工程**：信念植入思维、核心卖点独立成章

**货物崇拜检测（强制）**：大纲每个段落过2问——
1. 这一段删掉的话，片子少了什么？（如果答案只是"节奏感"或"过渡"，这一段就是竹子控制塔——有形式无实质）
2. 这一段能用一句话说清楚"观众看完这段应该知道/感受到什么"吗？（说不清楚=填充段落，砍掉或重写）

**论据应用**：基于阶段2的论据矩阵，应用四段式逻辑框架填充文案大纲。

**输出**：
1. 文案大纲（含：结构选型、段落分配、论据映射、技法运用）
2. 写入 `[项目名]S4V1.md`
3. 更新 `[项目名].md`

---

### 阶段 5：宣传片文案生成

**启动时**：读 `[项目名].md` + `[项目名]S4V1.md`

**创作核心**：
- 柔韧之力公式：外壳（情感/画面/节奏）+ 内核（数据/事实）
- 动词升级：用具体动词替代抽象描述
- 文学叙事体：避免说明文，追求画面感和节奏感

**技法应用**：调用 `content-tagger` 提取的文风标签做金句强化。

**反自欺检验（强制，在内部评估之前）**：
- 逐句读一遍文案，问：这句话是在让观众"感觉"什么，还是在让观众"知道"什么？（如果既没感觉也没知道=废话，删除）
- 有没有借术语逃避思考？（如"赋能""闭环""抓手"——每个这样的词必须替换成具体的动作或画面）
- 如果费曼读了这段文案，他会说"你到底想说什么"还是"懂了"？

**内部评估**（≥60分才可输出）：
- 旁白/字幕分层是否正确？
- 四段式逻辑是否完整？
- 是否有具体画面感？
- 金句是否有记忆点？

**输出**：
1. 宣传片完整文案（旁白 + 字幕分层）
2. 内部评估报告
3. 写入 `[项目名]S5V1.md`
4. 如需生成 DOCX：用 python-docx 生成，保存至 `[项目名]-文案.docx`

---

### 阶段 6：汇报文档生成（可选）

**目标**：生成给客户汇报的完整文档。

**内容**：项目概述 → 创意策略 → 文案全文 → 分镜建议 → 执行计划

**分镜衔接**：确认后移交分镜阶段，可衔接 `film-storyboard` 或 `petro-storyboard` 技能。

**输出**：
1. DOCX 格式汇报文档
2. 更新 `[项目名].md`（项目完成）
