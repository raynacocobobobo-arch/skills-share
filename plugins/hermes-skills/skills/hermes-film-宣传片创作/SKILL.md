# 宣传片创作全流程引擎

## 核心原则

宣传片没有一种固定的“正确写法”。先判断项目条件，再选择结构、数据密度和修辞强度。

优先级：

**用户/客户明确要求 > 播放场景与受众 > 项目素材逻辑 > Hermes 默认结构/修辞模板。**

方法论不能推翻用户/客户已经确认的项目事实、结构和口径；只能帮助更好实现它们。

---

## 任务模式：先分流，再决定走几阶段

| 模式 | 条件 | 默认流程 |
|---|---|---|
| A 从零创作 | 只有 Brief/素材，没有成型稿 | 完整六阶段 |
| B 结构重构 | 已有稿件，但明确要求推翻/重搭 | 保留事实资产，重点重走1/2/4/5 |
| C 基于现稿改稿 | “在这个版本上改”“保留结构优化”“不要重写” | 建立原稿基线，只做最小必要改动 |
| D 局部润色 | 指定某段/某句/某章 | 不扩大范围 |
| E 既有 Word 修改 | 上传已有 Word 并要求直接修改 | `宣传片创作` 管内容，`doc-reviewer` 管原文件保真 |

C/D/E 模式开始前必须列清：

- **必须保留**：已确认结构、事实、标题、句子、口径；
- **必须修改**：最新客户/会议/用户要求；
- **可优化**：措辞、节奏、过渡、信息密度；
- **禁止擅改**：用户未授权变化的内容。

**最小必要改动优先于“重新写一版更漂亮的”。**

## Reference Routing

当宣传片任务需要本 Skill 自带方法之外的专业参考书支持时，按分层路由读取，不直接加载整本专业书：

1. 先读取 `manifests/reference-router.md`；
2. 再读取路由指向的对应 `.index.md`；
3. 只有索引明确指向且当前问题确需深读时，才读取原文对应章节。

典型触发包括：政府/央国企汇报片的纪实表达、复杂解说词结构、画面与旁白关系、导演化视觉表达、纪录片方法或需要更深理论依据的结构判断。普通改稿若本 Skill 自带 references 已足够，不额外加载专业书。

专业参考书只能补充方法，不能覆盖 `LOCKED` 内容、客户口径、项目事实和来源优先级。

## 全局硬约束

### 1. 素材真实性
- 只使用用户提供/确认的素材、事实、数字、场景、人物和对话。
- 不为了画面感虚构事实。
- 多来源冲突时按受众适配 reference 的来源权威与状态规则处理。

### 2. 已确认内容锁定

关键内容标记：
- `LOCKED`：用户/客户已明确确认；
- `CONFIRMED`：正式资料支持；
- `TENTATIVE`：仍需确认；
- `CONFLICT`：来源冲突。

`LOCKED` 内容后续不反复质疑或自动重写，除非出现新冲突证据或用户主动解锁。

### 3. 旁白与字幕按“记忆优先级”分层

禁止机械执行“旁白不能出现数字”。

- **A级：必须听见**——决定规模、成果、行业位置、核心论证的数据/事实，可且通常应进入旁白。
- **B级：必须看见**——设备型号、详细规格、次级荣誉、多个相近参数，优先字幕/包装。
- **C级：可删除**——不改变核心认知、重复的信息。

真正的问题不是“是不是数字”，而是：**是否值得占用听觉带宽。**

### 4. 既有 Word 修改

用户要求“在这个 Word/版本上改”时：

- Primary: `宣传片创作` 负责内容判断；
- **Required supporting skill:** `doc-reviewer` 负责原 Word 副本、格式、结构和段落保真；
- 净稿也以原 Word 副本为基础修改，不能从空白文档重建相似内容冒充“基于原稿修改”；
- 仅当用户明确要求重新排版/新建文档时允许重建。

## 六阶段流程

### 阶段1：需求确认与传播任务

回答：
- 观众是谁？
- 使用场景是什么？
- 看完必须知道/相信/记住什么？
- 最大障碍是什么？
- 目标时长？
- 当前是 A/B/C/D/E 哪种任务模式？
- 哪些内容已 `LOCKED`？

**费曼检验：** ≤30字说清这部片真正要完成的传播任务。抽象词必须能落到事实、业务关系、动作或观众认知变化。

方向未确认前，不提前扩写完整文案。

---

### 阶段2：素材认知与证据矩阵

论据类型：
- 数据；
- 案例；
- 人物；
- 行为/工艺/流程；
- 情感；
- 历史。

每条关键证据补充四列：

| 字段 | 含义 |
|---|---|
| Source | 来源 |
| Status | LOCKED / CONFIRMED / TENTATIVE / CONFLICT |
| Priority | A必须听懂 / B必须看见 / C可删 |
| Channel | 旁白 / 字幕 / 画面 / 待定 |

`content-tagger` 只在确实需要文风/技法标签时调用；标签不能代替内容判断。

---

### 阶段3：创意方向参考（可选）

只在用户需要市场案例或多个方向时执行：
- 搜索同类型案例；
- 分析为什么适合当前受众和场景；
- 提2-3个方向。

用户只要“方向”时，不提前写完整大纲和正文。

---

### 阶段4：结构与大纲

结构不是固定四段式。可选：
- 时序；
- 版块；
- 论证；
- 复调；
- 企业/政府汇报型总分总；
- 客户已明确确认的结构。

`有没有 → 能不能 → 稳不稳 → 值不值` 是一种可选说服模型，不是强制完整性检查。

### 时长与信息预算（强制）

正文前确定：
1. 总时长；
2. 目标旁白字数区间；
3. 每章秒数；
4. 每章唯一核心认知；
5. 每章 A级口播事实/数据；
6. B级字幕信息；
7. C级删减信息。

如果要求更短，先删 C、转移 B，再压 A；不要靠加快配音和缩短字幕停留时间解决信息过载。

### 每段三问

- 删掉这段，片子少了什么？
- 观众看完应该知道/感受到什么？
- 相比上一段，认知推进了什么？

只有“过渡/气势/升华”而没有实质作用的段落，合并或删除。

---

### 阶段5：文案生成

写作优先级：

**准确 > 听觉清楚 > 项目专属性 > 节奏/画面感 > 修辞。**

- 政府/产业汇报：直接、正式、稳健，核心数据可口播；
- 招商/投资：证据和因果优先；
- 品牌/人物：可提高文学性、留白和情绪比例；
- 产品/技术：功能、差异、结果优先。

### 反自欺检验（强制）

逐句检查：
- 这句话让观众知道什么或感受什么？二者皆无就删。
- 抽象词是否在替代具体业务关系？
- 换成任何企业名仍成立吗？如果成立，优先重写。
- “不是A而是B”“如果说A那么B”是否只是把策划逻辑念给观众？
- A级事实是否真的让观众听见了？
- 是否无意改掉 `LOCKED` 内容？

### 金句/记忆句

不是硬指标。只有当一句话能压缩事实、完成判断、完成结构转折或显著提高理解时才保留。

内部评估使用 `宣传片创作-文学技法与评估.md` 的动态片型评分；不再以“旁白出现数字”扣分，也不要求固定数量金句。

---

### 阶段6：汇报文档（可选）

可包含：项目概述 → 创意策略 → 文案全文 → 分镜建议 → 执行计划。

既有 Word 改稿时，使用 `doc-reviewer` 在原文件副本上落地，不自动重排版。
