# 客户需求调查问卷设计方法

基于科特勒《营销管理》第4章"实施营销调研"（原文第1424-1543行）。

## 核心原则

**原文第1482行**：行为资料分析法——顾客的实际购买数据比口头陈述更为可靠。
→ 优先收集行为事实（做了什么），其次才是态度（觉得怎样）。

**原文第1501行**：消费者的现实行为与他们在调查问卷的回答并非总是一致。
→ 行为数据和态度数据矛盾时，信行为数据。

## 六步法（原文第1436行）

1. 界定营销问题 → 2. 编制调研计划 → 3. 收集信息 → 4. 分析信息 → 5. 展示结果 → 6. 制定策略

## 问卷设计规则（原文第1505-1515行）

1. 问句简单易懂：一个问句只问一件事，不复合
2. 问句具体明确：要求受访者翻记录而不是"回忆"
3. 避免专业术语
4. 避免模糊用词
5. 避免否定性用词
6. 备选答案不重叠

## 问句类型（原文第1494-1499行）

- 二分式：是/否
- 多项选择：三选一以上
- 评比量表：差→极好
- 开放式问句：仅用于收尾（"还有什么我没问到的？"）

## 恩万实践要点

- 不问"你觉得什么重要"，问消费清单里视频排第几
- 不问"你满不满意"，问发了朋友圈吗、推荐了吗、几个人问过
- 不问"你觉得市场谁好"，问第一个想到的名字、谁家活最多
- 客户说"质量好"但追问不出细节 → 信行为数据，不信口头陈述
- 客户说"都挺好" → 可能是不想说，换方式问
- 收尾必问："还有没有我没问到但你觉得该知道的事？"
