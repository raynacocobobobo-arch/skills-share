# AI Marketing Workflow

## Purpose

将传统营销顾问流程升级为基于 AI Workflow Principles 的 AI-assisted marketing workflow。

本流程继承 shared/ai-workflow 的核心原则：

- Problem First：从商业决策问题开始，而不是从输出格式开始。
- Context First：AI 分析必须建立在受控信息环境中。
- Verification Loop：AI 输出必须经过证据检查和人工判断。

AI 不替代营销战略判断，而是增强：

- 信息收集
- 市场分析
- 用户洞察
- 策略综合
- 决策材料制作

## Core Workflow

```
Business Question
        ↓
Context Gathering
        ↓
AI Analysis
        ↓
Strategic Synthesis
        ↓
Artifact Generation
        ↓
Verification & Human Review
        ↓
Final Decision Material
```

## 1. Problem First: Define Business Question

不要从：

"生成一个营销方案"

开始。

首先明确：

- 商业目标
- 决策问题
- 目标用户
- 需要验证的假设
- 成功评价标准

## 2. Context First: Build Marketing Context

AI 分析前，需要建立可靠上下文：

- 品牌资料
- 历史营销方案
- 用户数据
- 市场研究
- 竞争信息
- 客户资料

禁止脱离上下文直接生成营销策略。

## 3. AI-assisted Analysis

AI 可辅助：

- 市场趋势整理
- 用户洞察提取
- 竞争分析
- 机会识别
- 信息综合

AI 提供分析加速，不替代战略判断。

## 4. Artifact Driven Output

输出应形成可执行营销资产：

- Marketing Brief
- Strategy Deck
- Campaign Plan
- Customer Meeting Brief
- Content Outline

## 5. Verification Loop

遵循：

```
Generate
→ Check Evidence
→ Review Result
→ Human Decision
```

人工确认：

- 数据真实性
- 推理逻辑
- 商业可行性
- 品牌一致性

## Key Principle

AI Marketing Copilot 的价值不是替代营销专家，而是缩短：

```
问题定义
→ 信息获取
→ 分析判断
→ 决策输出
```

这一完整链路。
