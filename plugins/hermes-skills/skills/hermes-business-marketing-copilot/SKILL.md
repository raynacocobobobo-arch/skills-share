# 市场营销 Copilot

基于科特勒《营销管理》（中文版·53万字） + 视频制作行业实战知识。

## 知识库加载规则（强制）

回答任何营销问题前，先根据问题类型查下表定位章节，然后加载原文：

```
read_file('references/市场营销.md', offset=X, limit=200)
```

文件共 6030 行。

## Reference Routing

当营销问题需要接入共享专业书库时，不直接读取整本原文：

1. 先读取 `manifests/reference-router.md`；
2. 再读取路由指向的专业书 `.index.md`；
3. 只有索引明确指向且当前问题需要深读时，才读取原文对应章节。

典型触发：市场细分、定位、消费者/企业市场、竞争、定价、渠道、品牌、增长、营销传播或需要原著依据的诊断。共享书库用于按任务深化，不替代本 Skill 已有的营销框架和现实信息核验规则。

## 通用营销工具箱

### 4P（企业视角）
- **产品**：质量、设计、特色、品牌、服务、担保、退货
- **价格**：标价、折扣、返利、付款期、赊销条件
- **渠道**：覆盖面、产品组合、地点
- **促销**：广告、人员销售、直复营销、公共关系

### 新4P（管理视角）
- **人员**：将消费者看成人，了解其生活
- **流程**：营销管理中的纪律与结构
- **方案**：所有面向消费者的活动
- **绩效**：财务与非财务指标（品牌资产、道德、环境、法律、社会）

### 4A（消费者视角）
- **可接受性**：产品或服务超出消费者期望的程度
- **支付能力**：目标市场有能力并愿意支付的程度
- **可达性**：消费者能方便获取产品的程度（可得性+便利性）
- **知晓度**：消费者知道产品、了解产品、确信产品值得购买的程度

### 70/20/10 预算分配
- 70% 投已验证有效的渠道
- 20% 优化现有渠道
- 10% 实验新渠道

## 诊断速查表

| 问题 | 先查 |
|------|------|
| "为什么客户选他不选我" | 知晓度 + 可达性 |
| "为什么产品好但没流量" | 分发渠道 + 付费推广 |
| "价格该定多少" | 4A 支付能力（客户愿意付多少 > 成本+利润） |
| "怎么打败竞争对手" | 渠道 + 传播（不要拼质量，要拼分发） |
