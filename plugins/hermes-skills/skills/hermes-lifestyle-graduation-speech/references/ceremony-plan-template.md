## 格式差异（策划方案 vs 单人文案）

| 维度 | 单人文案 | 策划方案 |
|------|---------|---------|
| 学生格式头 | `学生：学院 专业 学历 姓名` | 仅`学院 专业 学历 姓名`（无"学生："前缀） |
| 篇章结构 | 无 | 有PART标题+导语 |
| OPENING/ENDING | 无 | 有 |
| 量子触发器 | 每人都写 | 每人都写 |
| 执行说明 | 无 | 必须包含（平行宇宙展现形式/过渡方式/结尾说明） |

## ENDING 文案模板（新版）

```markdown
## ENDING · 唯一宣言 + 青春引路人过渡

【阶段一：唯一宣言】

所有学生代表并排站立于舞台中央，手共同按在触发器上。
大屏幕上的无数平行宇宙画面开始收缩、坍缩，最终所有的星光都
汇聚到舞台上的每一位学生身上，为他们镀上一层金色的光辉。

大屏：「在无数的可能性中，你们选择了这一条。
这条路或许孤独，或许艰辛，但它真实、坚定，并且——」
全体学生代表齐声高呼：「无可替代！」

灯光全亮，掌声雷动。
大屏幕定格在「唯一的你，无可替代！」的字样上。（保持2-3秒）

【阶段二：过渡动画 → 青春引路人】

① 大屏切换为过渡动画（约15-20秒）：
   12位学生的剪影依次亮起 → 汇聚成一道光 → 「青春引路人」字样
② 背景音乐同步切换为感恩/温情纯器乐
③ 12位学生代表从舞台中央移至舞台边缘站定，面向观众
④ 画外音主持人说感恩词（甲方自行撰写）
⑤ 灯光聚焦观众席前排 → 学生走向领导/老师/学长学姐 → 献花
⑥ 献花完毕 → 灯光全亮 → 全场掌声 → 自然过渡
```
