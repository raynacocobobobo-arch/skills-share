# Creative Framework Routing

## Purpose

本文件用于连接故事片创作 Skill 与 Creative Framework。

Skill 负责：
- 判断任务模式；
- 管理修改权限；
- 保证事实、因果、人物和可拍性。

Creative Framework 负责：
- 提供创作判断视角；
- 判断当前问题属于哪类专业创作问题。

## Routing

### 故事结构、人物弧、主题不足

优先读取：

`shared/creative-framework/film/screenwriting-directing.md`

适用于：
- 人物没有变化；
- 冲突不足；
- 高潮不成立；
- 主题没有通过行动体现。

### 镜头、画面、分镜问题

优先读取：

`shared/creative-framework/film/storyboard-directing.md`

适用于：
- 用户要求少对白、多画面表达；
- 分镜像拍摄清单；
- 节奏和视觉信息不足。

## Principle

不要先调用大量专业资料。

先判断问题类型，再读取对应方法论，最后根据需要进入专业书原文。
