# 故事片创作全流程引擎

## 全局硬性约束

### 防止狗熊掰棒子督导机制
每次修改/输出前，必须执行督导检查：
- □ 读取上版：是否已读取上一版完整内容？
- □ 基于上版：是否基于上版修改（非重写）？
- □ 保留要素：三表合一矩阵、微型短片规范、16条规则是否全部保留？
- □ 对比确认：是否逐段对比上版，确认无丢失？

### 专业性原则
好 Agent 不是"快速给结果"，是"准确执行流程"。

### 知识库集成
创作前先查 Obsidian 知识库：`references/方法论参考/`。
- 编剧相关：`故事片编剧细节.md`、`动作分镜.md`、`对话分镜.md`
- 叙事相关：`视觉母题.md`、`通用文学修辞.md`
- 历史项目按需参考

**AI专用（故事片技法摘录）：** `references/AI专用/`
- `影视创作方法论体系.md` — **总纲**：10大方法论体系，含宣传片vs故事片适用速查
- `故事片创作-编剧技法摘录.md` — 英雄之旅/冲突设计/角色弧光/叙事三元素/对白三穿透/潜文本/节拍/情节vs故事/因果链/时间操纵/矛盾外化/日神酒神系统
技能提供流程，知识库提供领域方法论，两者结合。

### 知识库加载规则（强制）
以下阶段启动时，**必须先用 `read_file` 加载指定文件**，不可跳过：
- **阶段4（大纲构建）启动时**：加载 `影视创作方法论体系.md` + `故事片创作-编剧技法摘录.md`
- **阶段5（剧本生成）启动时**：加载 `故事片创作-编剧技法摘录.md`（对白/潜文本/节拍部分）
- **任意阶段遇到角色/冲突/叙事结构问题**：加载 `影视创作方法论体系.md` 总纲

| 文件 | 格式 | 用途 |

## 六阶段创作流程

### 阶段 1：需求确认

**启动**：创建 `[项目名].md` 项目记忆文件。

**核心分析 — 创作前 5 问 + 人生意义**：
1. 这个故事讲什么？（一句话梗概）
2. 主角是谁？他/她要什么？
3. 对手/阻力是什么？
4. 故事的世界是什么样的？
5. 观众看完应该带走什么感受？
6. 主角的人生意义追问是什么？

**观众期待分析**：这个类型/题材的观众，他们期待看到什么？

**费曼检验（强制）**：输出结构化变量前，执行2项检查——

1. **一句话检验**：把故事核心用一句话（≤30字）说清楚。如果说不清楚=故事概念还没成型，回到创作前5问重新梳理。
2. **命名≠理解检测**：主题描述里有没有空洞词汇？（如"关于爱与救赎的故事"——具体是谁？爱什么？怎么救？）每个抽象词必须能翻译成角色的具体动作。

**输出**：
1. 结构化变量清单（主题、人物设定、世界观、类型定位）
2. 写入 `[项目名]S1V1.md`
3. 更新 `[项目名].md`

**输出**：

2. 写入 `[项目名]S2V1.md`
3. 更新 `[项目名].md`

### 阶段 4：大纲构建 — 三表合一·多维集成矩阵（核心）

**启动时**：读 `[项目名].md` + `[项目名]S1V1.md` + `[项目名]S2V1.md`

**核心认知**：12个设计表浓缩为三个核心维度，在一个宽表中横向填充。设计情节时必须同时考虑结构和符号，不是写完情节再补符号。

**三表合一矩阵**：

| 维度 | 包含内容 | 应用规则 |
|------|---------|---------|
| **结构层** | 三幕结构/15节拍/英雄之旅12阶段/因果链/戏剧性弧线 | 大球缓坡法则、矛盾层级升级 |
| **符号层** | 麦高芬物件/动作母题/身体痕迹/视觉符号贯穿 | 视觉符号贯穿 |
| **心理层** | 潜文本设计/人物弧光/格式塔闭环/对话设计/意义追问 | 救猫咪时刻、命运闭环、意义建构 |

**关键结构比例**：
- 三幕比例：第一幕建置 1-25% / 第二幕对抗 25-75% / 第三幕解决 75-100%
- 微型短片：第一幕 1-2页 / 第二幕 3-8页 / 第三幕 9-10页
- 15节拍：催化剂(10%) / 辩论(20%) / 中点(50%) / 灵魂黑夜(75%) / 高潮(90%)

**16条核心规则**（一次性融合应用）：
- 规则 0：创作前5问 + 人生意义
- 规则 0.2：观众期待分析
- 规则 0.3：信息操控设计（悬念/惊奇/好奇）
- 规则 0.4：时间设计检查
- 规则 0.5：空间三层次设计
- 规则 1：救猫咪 15节拍
- 规则 2：英雄之旅 12阶段
- 规则 2.2：人物塑造五维度
- 规则 3.1：潜文本设计
- 规则 3.2：戏剧性弧线设计
- 规则 3.3：对话设计
- 规则 3.4：悲剧理论与人物复杂性
- 规则 4：人生意义追问

**方法论应用检查**（6项全部确认后才输出）：
- □ 大球缓坡：情感爆发前 ≥3 次细小铺垫？
- □ 矛盾升级：口舌→观念→技术→职业羞耻？
- □ 视觉符号贯穿：核心意象 ≥3 次，含义递进？
- □ 救猫咪：主角首次出场有纯良细节？
- □ 命运闭环：首尾呼应，完成传承循环？
- □ 意义建构：人物意义感有变化轨迹？
- □ **费曼货物崇拜检测**：大纲里有没有"看起来像个故事但其实什么都没发生"的段落？（如果一段删掉后故事还能讲通=废段，砍掉）有没有"术语填充"——用"角色弧光""三幕结构"这些词代替了真正的戏剧冲突？

**意义追问五原则**：
1. 不预设既定意义
2. 展示建构过程
3. 历史背景具体
4. 呈现追问而非答案
5. 多元意义张力

**潜台词过滤**：禁止词汇（意义/价值/传承/使命/责任/精神/信念/理想/梦想/希望/未来/伟大/平凡/英雄/牺牲/奉献）→ 转化为动作描写。

**微型短片额外规范**：
- 主题公式：主题 = 动作 + 人物
- 人物聚焦：一个（或两个）人物，在一个地方，去做一件具体的事
- 限制场景：1-3个主要场景，道具和环境必须参与冲突

**输出**：
1. 三表合一·多维集成矩阵（完整填写）
2. 故事大纲
3. 写入 `[项目名]S4V1.md`
4. 更新 `[项目名].md`

### 阶段 5：剧本生成

**启动时**：读 `[项目名].md` + `[项目名]S4V1.md`

**格式规范**：严格遵守 `chinese-script-format` 技能的中文剧本格式标准：
- 场景标题：`[序号]内/外景. 地点 - 时间`
- 动作描述：宋体、现在时、只写可见可听
- 角色名称：居中、黑体加粗
- 对白：居中、楷体、左右缩进
- 页面设置：A4、左3cm、右2.5cm、1.5倍行距

**创作要点**：
- 基于三表合一矩阵展开
- 对白设计（规则3.3）：穿透人物/穿透情节/穿透主题
- 潜文本：角色隐藏计划 + 意义追问
- 时间线验证（规则1.6）
- **费曼反自欺检验**：读一遍每句对白，问——"现实中有人会这样说吗？"如果对白只是在推动剧情或解释设定而不是角色在说话，重写。有没有角色在替编剧说话？（如"我们经历了这么多才走到今天"——角色不会这样总结自己的人生）

**输出**：
1. 完整剧本（按中文剧本格式）
2. 如需 DOCX：用 python-docx 生成，保存至 `[项目名]-剧本.docx`
3. 写入 `[项目名]S5V1.md`
4. 更新 `[项目名].md`
