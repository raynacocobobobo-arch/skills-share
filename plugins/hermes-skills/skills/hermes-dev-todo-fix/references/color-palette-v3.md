# 花叔Design v3 · 纯黑白配色规范

## 设计哲学

"只有黑，白，可以黑白交替，要有文艺气息"

纯黑白影调 — 靠灰度层次建立信息层级，不依赖任何彩色。文艺气息来自字间距、留白、斑马纹交替。

## 灰度七级

| Token | Hex | 用途 |
|-------|-----|------|
| `bg` | `#FFFFFF` | 主底色 |
| `bgAlt` | `#F5F5F5` | 交替底色 (列表斑马纹) |
| `ink` | `#000000` | 主文字 / accent / 选中态 |
| `gray4` | `#444444` | 深灰 — 强调文字 / 情境图标 |
| `gray7` | `#777777` | 中灰 — 次要文字 / 日期 / 按钮 |
| `grayA` | `#AAAAAA` | 浅灰 — 完成态文字+图标 / 低优先级 |
| `grayD` | `#DDDDDD` | 线灰 — 圆框 / 分隔 / 未勾选圆圈 |
| `grayEA`| `#EAEAEA` | 极淡灰 — 备用 |

## 应用规则

| 元素 | 颜色 |
|------|------|
| 页面背景 | `bg` |
| 列表奇数行 | `bg` |
| 列表偶数行 | `bgAlt` |
| 主导航文字 | `ink` |
| segmented control 选中 | `ink` 底 + `bg` 字 |
| 任务标题 | `ink` |
| 已完成任务 | `grayA` + strikethrough |
| 日期 (未过期) | `gray7` |
| 日期 (已过期) | `ink` `.fontWeight(.medium)` |
| 情境名称标签 | `gray7` + `grayD` 描边框 |
| 重音符 | 无 — 用 `ink` 字重区分 |
| 删除 swipe | `gray7` |
| 完成 swipe | `gray4` |
| 今天/明天 swipe | `gray7` / `ink` |
| 分隔线 | `grayD` |
| 勾选圆圈 (未完成) | `grayD` |
| 勾选圆圈 (已完成) | `grayA` |
| 月历选中日 | `ink` 实心圆 + `bg` 白字 |
| 月历今天 | `bgAlt` 底 + `ink` 黑字加粗 |
| 月历任务标记点 | `ink` 35% 透明度小圆点 |
| 番茄钟背景 | 纯黑 |
| 番茄钟文字 | 白色 |
| 番茄钟进度环 | 白色 |
| 输入框背景 | `bgAlt` |
| + 按钮 | `ink` |
| 语音按钮 (非录制) | `gray7` |
| 语音按钮 (录制中) | `ink` |
| toast 撤销按钮 | `ink` `.fontWeight(.semibold)` |
| 导航栏/工具栏背景 | `bg` |

## 禁止项

- ❌ 任何彩色 hex (红/蓝/绿/紫/橙/粉)
- ❌ 任何渐变色
- ❌ 系统默认 `.blue` / `.green` / `.red` / `.orange`
- ❌ 彩色 emoji 图标作为功能标识
- ✅ 只用灰度 Color extension token
