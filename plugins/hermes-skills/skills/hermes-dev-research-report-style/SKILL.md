# 分析报告写作方法论

从B站每日研报系统提炼的通用报告写作规范。适用于任何需要呈现多角度分析、给出可操作结论的报告场景。

## 核心原则

### 1. 辩证制衡
每个做多/正面观点必须配反方论点。读者看完一个方向，立刻看到对立面。不允许单方面渲染。

### 2. 叙述式自然语言
无表格版报告读起来应该像人写的分析，不像数据库dump。
- ✅ 允许：「上证4098，收于5日线下方，缩量深V但抛压衰竭」
- ❌ 禁止：「**指标**：上证 | **数值**：4098 | **状态**：●黄 | **解读**：缩量」

### 3. 板块整合
报告板块不应超过8个。相似信息合并，重复内容删除。
- 大盘诊断（数据+验证合并）
- 多空阵营（仅分布，不重复标的）
- 主线与行业（逻辑+配置+中长期合并）
- 操作与行动（策略+清单合并）

### 4. 信息密度优先
- 个股/标的全部列举，不遗漏
- 关键数字（点位/量能/估值）全保留
- 逻辑链保持完整（A→B→C）
- 模糊表述不纳入（如"还有空间"、"可能有机会"）

## 色标规范

| 颜色 | ● 色 | 含义 | 场景 |
|------|------|------|------|
| 红 | ●红 RGB(190,30,30) | 看空/卖出/高风险 | 风险提示、回避建议 |
| 黄 | ●黄 RGB(220,170,0) | 谨慎/观望/中性 | 条件未满足、等待信号 |
| 绿 | ●绿 RGB(30,140,30) | 看多/买入/安全 | 确认信号、持有建议 |

禁止用 emoji（🔴🟡🟢），部分终端不显示。

## 板块设计原则

好的报告板块有清晰的逻辑流：
```
抓眼球（金句）→ 给数据（点位/大盘）→ 给判断（多空/主线）
→ 给论据（分析师观点）→ 给执行（策略/行动）→ 给底线（情景/风险）
```

每个板块只做一件事，不跨界：
- 📊 大盘诊断 = 只呈现数据，不做判断
- ⚖️ 多空阵营 = 只分阵营，不列个股
- 🧭 主线与行业 = 逻辑+配置，不写操作
- 🗣 分析师观点 = 论据支撑，个股穷举
- 🎯 操作与行动 = 具体执行，不给逻辑
- 🎲 情景推演 = 模拟未来，含概率
- ⚠️ 风险矩阵 = 底线思维，不避重就轻

## 输出规范

### 有表格版
- 表格样式：深色表头（#252525底+白字黑体）+细线边框（#999）+隔行浅灰（#F5F5F5）
- 色标用●，表内自动着色
- 正文宋体11pt，表体9.5pt，标题黑体
- 禁止等线字体（兼容性差）

### 无表格版
- 所有表格板块用自然段落重写
- 多空全景：「看多7人：A/B/C。谨慎2人：X/Y。无人看空。」
- 行业配置：「●绿 AI光模块(7/0/0)：全员看多，仅大摩提示高估值」
- 禁止出现 `**列名**：值 | **列名**：值`

## 报告骨架

```
开篇
  ├── 标题（即核心判断）
  ├── 金句（2-3条，观点+冲击力）
  ├── 关键点位/数据速览
  └── 核心结论（一句话）

正文
  ├── 大盘诊断（数据+校准）
  ├── 多空阵营（分布，不重复）
  ├── 主线与行业（逻辑+配置）
  ├── 各来源观点（论据，穷举）
  ├── 操作与行动（策略+清单）
  ├── 情景推演（模拟，含概率）
  └── 风险矩阵（底线，不自欺）

尾部
  └── 行动清单（持有/等待/回避/关注）
```

## 适用场景

- 投资研报（股票/行业/宏观）
- 竞品分析报告
- 项目决策分析（多方案对比）
- 任何需要"呈现多角度→给出可操作结论"的场景
