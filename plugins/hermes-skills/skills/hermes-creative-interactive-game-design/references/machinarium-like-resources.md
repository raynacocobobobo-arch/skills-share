## 阅读顺序

1. The Art of Game Design：确定核心体验。
2. Game Design Workshop：写设计文档和原型计划。
3. Don’t Make Me Think：梳理点击、反馈、可理解性。
4. Framed Ink：做场景构图和视线引导。
5. Jonathan Blow / GDC 谜题设计：优化谜题系统。

## 10分钟 Demo 起点

> 一个小机器人在废弃修理铺醒来，通过修好老式收音机，打开通往城市街道的门。

用于练：

- 场景美术
- 点触交互
- 道具组合
- 环境叙事
- 谜题反馈
- 角色动画
