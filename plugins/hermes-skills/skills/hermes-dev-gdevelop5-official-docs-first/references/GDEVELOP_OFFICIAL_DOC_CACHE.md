## 文档条目：Platform behavior Reference（空中再次跳跃）
- 官方标题：Platform behavior Reference

- 适用范围：平台角色落地判断、空中再次跳跃、模拟跳跃输入。

## 文档条目：Keyboard Reference（当前 JSON 内部类型）

- 查询日期：2026-06-21
- 适用范围：二段跳键盘输入。
- 关键结论：

## 文档条目：Audio / Sounds and music Reference
- 官方标题：Audio / Sounds and music Reference - GDevelop documentation
- 官方链接：https://wiki.gdevelop.io/gdevelop5/all-features/audio/；https://wiki.gdevelop.io/gdevelop5/all-features/audio/reference
- 查询日期：2026-06-22
- 适用范围：GDevelop 音频资源、播放音效/音乐事件动作。
- 关键结论：
1. 短音效应使用 Play a sound；大文件/BGM 用 music。
2. Play a sound 的 JSON 内部类型为 `PlaySound`，参数包含内部空参数、音频资源名、是否循环、音量、音高。
3. 播放音频前通常需要玩家与游戏交互以解锁浏览器音频；跳跃按键属于交互后触发。
4. 官方将 AAC 列为背景音乐/大音频的通用支持格式，并说明 AAC 在浏览器和操作系统（含 iOS）上广泛支持；MP3 只属于部分平台支持。
- 对本项目的用法：短音效继续使用 PlaySound，BGM 继续使用 PlayMusicOnChannel；素材瘦身时可以把事件和资源表中的 MP3 成套迁移为 AAC。
- 不允许误用的地方：不要只转文件而遗漏普通事件、JS Code 字面量或 resources 表；不要把大 BGM 改为 PlaySound。
