# 扒词文档修整

## 核心约束

**只能删不能加**——音频已录制，不能更改音频内容。只能删除字/词/句，不能替换或新增词汇。

## 修整类型（按优先级）

### 1. 语气词删减
删：呢、啊、呀、嘛、吧、嗯、噢

### 2. 口头冗余删减
删：那（句首）、那么（句首）、这个、那个、就是说、我们说的是、等等（多余时）、然后

### 3. 重复/口误修复
- 重复字：能**能**够 → 能够
- 多余"的"：比较**的**平和 → 比较平和
- 多余"一个"：很多**的一个**功效 → 很多功效
- 多余"我们的"：**我们的**春秋战国 → 春秋战国
- 句尾残词：千年智慧**但是** → 千年智慧

### 4. 孤立半句删除
口误导致的不完整半句，无法补全的整行删除

### 5. 错别字/措辞修正（仅删不改字）
- 特邀**约**友人 → 特邀友人（删"约"）
- 他给**他妈**开了 → 他给**他母亲**开了（书面化）
- 说的**的** → 说**得**
- 西方文化**一样**那么清晰 → 西方文化那么清晰（删"一样"）

## 格式规范

### 术语标识
- 中医/专业术语加**中文引号**：「卫气」「营气」「道地药材」
- 比喻/特殊用法的词加**双引号**："死"

### 语境补充
- 口语中省略的背景信息加**圆括号**补充：（外国）（年龄段是）（人群）

### 标点规范
- 书名加**书名号**：《五十二病方》《本草纲目》
- 并列项之间保留空格或顿号

### 段落节奏
- 按说话者的自然气口拆分段落（独立成行的短句）
- 原文一行空一行的格式**保留**

## 输出格式

1. 生成 **Word 文档**（.docx），修改处**加粗**
2. 不要用 Markdown 格式
3. 保留源文件的行间距（一行内容、一行空行）
4. 附完整修改清单（编号、原文→改后）

## 🚨 第一遍必踩的坑

**症状**：扫读一遍就交差，只发现 10 来处修改。用户一眼看出大量遗漏。
**根因**：扫读只能看到错别字和显眼的语气词。口语中大量"那/那么/这个/我们的/的"冗余在扫读时被大脑自动忽略，必须逐句停下来问"这句话写成书面语，哪里卡"才能发现。

**✅ 正确做法**：全文至少读两遍。第一遍标记显性问题（错别字、重复字），第二遍逐句读——**每一行都在脑子里过一遍"印成书什么样"**，感受不顺的地方，那就是需要删的冗余。注意：这只是定位工具，不是真的要改写，落手仍然是只删字不加字。完成后自查：如果修改量不到原文行数的 10%，大概率漏了。

## 逐句读时的具体检查点

对每一行依次问：
1. 「呢/啊/呀/嘛/吧/嗯」？→ 删
2. 句首有「那/那么」？→ 删
3. 有「这个/那个/这种」但非必要指代？→ 删
4. 有「我们的/你们/我们」但上下文已明确主体？→ 删
5. 「的」字是否多余？（"比较的平和"→"比较平和"）
6. 「一个/一些」是否冗余？（"很多的一个功效"→"很多功效"）
7. 句尾是否被截断？（"千年智慧但是"→"千年智慧"）
8. 前后行是否重复同一句话的不同版本？→ 删重复行
9. 是否有孤立半句无法补全？→ 整行删除

## 工作流程

1. 通读全文，了解内容主题和说话者
2. **第一遍**：扫读标记错别字、重复字、显眼语气词
3. **第二遍**：逐句按上述 9 条检查点过，每行问"写成书面语卡在哪"
4. 特别关注 30 分钟以上的长访谈——后半段疲劳期错误率明显升高
5. 自查：修改量是否 ≥ 原文行数的 10%？不够就再读第三遍
6. 生成 Word 文档，所有修改处加粗
7. 输出完整修改清单（每条完整列出原文→改后）供用户审核
6. 用户确认后可二次调整
