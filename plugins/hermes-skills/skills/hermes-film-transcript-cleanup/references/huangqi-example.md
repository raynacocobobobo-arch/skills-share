# 黄芪解说词修订案例

来源：新华网《国学遇见国医》第三季本草篇·黄芪（约45分钟访谈实录）

## 修订统计

- 原文约 200 行（含空行）
- 第一次修订：11 处（扫读，遗漏严重）
- 第二次修订：132 处（逐句读，覆盖语气词/冗余/重复/口误/孤立句）
- 用户二次加工：采纳 128 处（97%），另做措辞润色和格式规范

## 典型修改分类

### 语气词（高频删除）
呢、啊、呀、嘛 → 逐句检查句尾和句中

### 口头冗余（逐句找）
那/那么（句首）→ "那请问李主任" → "请问李主任"
这个/那个（多余限定）→ "呼吸的这个气" → "呼吸的气"
我们的（上下文已明确主体）→ "我们的春秋战国" → "春秋战国"
就是说/我们说的是 → 直接删

### 重复/口误
特邀约友人 → 特邀友人（约字赘余）
能能够 → 能够
黄芪这个故 → 黄芪（口误截断）
比较的平和 → 比较平和（口语中多余的"的"）

### 错别字/措辞
说的就特别形象 → 说得特别形象
他给他妈开 → 他给他母亲开（书面化）
西方文化一样那么清晰 → 西方文化那么清晰（删冗余"一样"）

### 孤立半句（整行删除）
"气阴两虚的" — 前文已提，此处为说话者重复开始的残句

## 用户格式规范（二次加工加入）

- 专业术语加中文引号：「卫气」「营气」
- 比喻义加双引号："死"
- 省略语境加括号：（外国）（年龄段是）（人群）
- 书名号规范：《五十二病方》
- 按气口拆分段落

## 教训

**扫读 vs 逐句读**：第一遍扫读只看出 11 处（错别字和显眼语气词）；第二遍逐句"印成书什么样"才抓到 132 处。修改量不到原文行数 10% 就说明漏了。
