# Generate Realistic Content Workflow

## Input

- character asset
- environment photo
- outfit reference
- pose requirement

## Process

1. Analyze environment:
- camera angle
- perspective
- lighting
- depth

2. Place character:
- scale
- position
- posture

3. Generate composite.

## Quality

The character should look like it was photographed in the original scene.

Check:
- identity
- perspective
- shadow
- color
- realism
