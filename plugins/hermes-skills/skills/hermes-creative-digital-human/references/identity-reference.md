# Digital Human Identity Reference

## Principle

Identity stability is the primary goal of a digital human.

A realistic character that stays consistent is more valuable than a visually perfect but unstable character.

## Identity Priority

When generating or editing:

1. face identity
2. body proportion
3. style consistency
4. clothing
5. scene styling

## Required References

A reusable digital human should maintain:

- front face reference
- three-quarter face reference
- side face reference
- full body reference

## Generation Rule

Always use existing identity references when creating new content.

Avoid:

- creating a new face for each image
- changing age randomly
- changing body proportions randomly

## Production Goal

The audience should perceive one real person producing different content in different locations.
