# Xiaohongshu Pose & Shot Library

这是一组小红书真人感照片的快捷参考。编号只用于内部调用，用户不需要记编号；自然语言描述优先。

## 使用原则
- 姿势要像真实拍照动作，不要像棚拍模特定点摆姿。
- 一个动作只解决身体姿态；人物身份、服装和场景由各自参考控制。
- 同一组图避免连续使用几乎相同的站姿和机位。
- 手部动作复杂时优先简化，避免为了“有动作”制造不自然肢体。

## 自然语言匹配
用户说“自然一点”“像抓拍”“别太摆拍”时，优先选择 P06/P07/P08/P20 与 S08/S10/S12 的组合。

用户说“突出穿搭”时，优先 P01/P02/P04/P09/P10 与 S01/S02。

用户说“环境多一点”时，优先 S04/S05/S11。

用户说“摄影师工作状态”时，优先 P21–P24，并根据动作选择 S12 或 S03。
