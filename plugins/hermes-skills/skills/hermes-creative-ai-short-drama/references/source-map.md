## Implementation rule

Before adding material to any V1 file:

1. Find its exact target in this table.
2. Keep `architecture-only` sources closed while drafting prose and schemas; use only the high-level retained concept recorded here.
3. Add or revise a row before introducing a new source path or retained concept.
4. Keep all executor, UI, database, LoRA, digital-human, and publishing logic out of V1.
